두 행성의 합주 / Two orbital rhythms

7번 원작 영상 · Original video

교사용 25분 활동지

두 행성은 오른쪽 기준점을 지날 때 각자 한 음을 냅니다. 학습자는 주기와 동시점을 예측하고, 같은 운동을 다른 음악과 화면으로 표현합니다. 종이 한 장 또는 말로 답해도 됩니다.

  1. 0–5분 · 예측. 0박에서 함께 출발합니다. 안쪽은 두 박마다, 바깥쪽은 세 박마다 돌아옵니다. 0부터 12까지 두 줄의 박자표에 각 행성의 귀환을 표시하세요. 다음에 함께 도착할 박을 동그라미 치고 이유를 적으세요.
  2. 5–11분 · 모델 수정. 아래 실습을 무음으로 한 번 실행하세요. 오른쪽 표식과 장면 아래 글로 귀환을 확인합니다. periods = [2, 4]로 고치기 전에 첫 동시점을 예상하세요. 바꾼 줄, 예상, 관찰한 박을 적으세요.
  3. 11–17분 · 작곡과 감상. 주기를 고정하고 두 시안을 만드세요. A에서는 두 리듬이 구별되게, B에서는 합주 순간이 두드러지게 합니다. 음정·음색·강약과 명암·시점·구도에서 각각 한 가지를 고르세요. 짝에게 의도를 말하기 전에 어떤 순간이 두드러졌는지 묻고 한 곳을 수정하세요.
  4. 17–25분 · 전이와 설명. 3박과 4박일 때 첫 동시점을 새 박자표로 설명하세요. “나는 ___을 강조하려 했다. 친구는 ___을 알아차렸다. 그래서 ___을 ___으로 바꿨다.”를 완성하세요.

교사 답안. 출발을 제외한 첫 동시점은 (2,3)에서 6박, (2,4)에서 4박, (3,4)에서 12박입니다. 무음·색각 차이·화면읽기 환경에서는 안쪽/바깥쪽 위치, 문자 I/O, 아래 귀환 기록과 박자표를 이용하세요.

학교급. 초등은 교사와 기준점을 가리키며 관찰하고 손뼉이나 그림으로 답합니다. 중등은 모델 한 줄을 고쳐 두 시안과 수정 이유를 제출합니다. 고등은 관측표에서 두 천체의 공전 주기와 단위를 인용해 주기비를 계산하고 모형과 비교합니다. 원궤도·일정한 속도·임의의 반지름과 시간 축척이 비교에 미치는 영향을 설명합니다.

평가 기록

네 항목을 각각 0–2점으로 기록하세요. 0은 근거가 없는 경우입니다.

  1. 과학적 예측. 1은 박을 예측함, 2는 관찰 전 예측과 공배수의 근거를 제시함.
  2. 코드와 결과. 1은 바꾼 값을 찾음, 2는 바꾼 줄과 관찰한 귀환 박을 연결함.
  3. 표현 의도. 1은 음악 또는 화면 선택을 명명함, 2는 음악과 시각 선택이 어느 리듬 또는 동시점을 강조했는지 설명함.
  4. 감상 후 수정. 1은 동료 의견을 적음, 2는 그 의견에 따라 한 편집을 전후 결과와 연결해 설명함.

25-minute teacher worksheet

Each planet sounds a note when it returns to its marker on the right. Ask learners to predict the returns, then compose two interpretations of the same motion. Accept spoken, drawn or written responses.

  1. 0–5 min · Predict. Start together on beat zero. The inner planet returns every two beats and the outer every three. Mark each return on two rows numbered 0–12. Circle the next shared beat and give a reason before running.
  2. 5–11 min · Test the model. Run once muted. Follow the right-hand markers and the caption. Predict the next shared beat before changing the line to periods = [2, 4]. Record the edited line, prediction and observed beat.
  3. 11–17 min · Compose and listen. Keep the periods fixed. Make version A distinguish the rhythms and version B emphasize their meeting. Choose a pitch, timbre or loudness and a contrast, viewpoint or arrangement. Ask a partner which moment stood out before revealing your intention. Revise one choice.
  4. 17–25 min · Transfer and explain. Draw a fresh beat grid for periods three and four. Explain your first coincidence. Finish “I wanted to emphasize ___. My partner noticed ___. I changed ___ to ___ because ___.”

Teacher key. After departure, (2,3) first coincide on beat 6, (2,4) on 4 and (3,4) on 12. The inner/outer positions, I/O captions and return list below support muted use, colour differences and screen-reader review.

By age. Elementary pupils observe with a teacher and point, clap or draw. Middle-school pupils edit a model, make two versions and explain a revision. High-school pupils cite measured orbital periods and units from an observational table, calculate a ratio and compare it with the model. Discuss circular paths, constant speeds and the choice of time and distance scales.

Assessment record

Score each dimension separately. Award 0 when there is no evidence.

  1. Scientific prediction. 1 predicts a beat. 2 predicts before testing and justifies it using common multiples.
  2. Code and outcome. 1 names a changed value. 2 connects the edited line to an observed return beat.
  3. Artistic intent. 1 identifies a musical or visual choice. 2 explains how musical and visual decisions emphasized a rhythm or a coincidence.
  4. Revision after critique. 1 records peer feedback. 2 explains a specific edit in response and compares the two versions.

periods = [2, 3]
radii = [1.4, 2.4]
scene.range = 3.2
planets = []
for r in radii:
    ring(axis=vector(0, 0, 1), radius=r, thickness=0.012)
    sphere(pos=vector(r, 0, 0), radius=0.07)
    planets.append(sphere(radius=0.19, color=color.cyan))
for frame in range(241):
    rate(20)
    hits = ""
    for i in range(2):
        lap = 20 * periods[i]
        phase = frame % lap
        angle = 2 * pi * phase / lap
        planets[i].pos = radii[i] * vector(cos(angle), sin(angle), 0)
        if phase == 0:
            hits = hits + ["I", "O"][i]
    if hits:
        scene.caption = str(frame // 20) + " | " + hits
