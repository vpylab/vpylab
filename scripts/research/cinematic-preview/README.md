# 빛과 소리 렌더링 비교

같은 학생 코드에서 생성한 명령으로 태양·지구·달과 다섯 음 건반을 비교하는 독립 시연입니다. WebGL 2를 우선 사용하며, 사용할 수 없는 환경에서는 같은 좌표를 Canvas 2D로 투영합니다. 기본 모드는 기존 재질 설정을 재현합니다. 두 모드 모두 시연 전용 카메라와 입력 처리를 사용합니다.

저장소 루트에서 실행합니다.

```sh
npm ci --prefix client
python3 scripts/research/cinematic-preview/build-scenes.py
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저로 http://localhost:8000/scripts/research/cinematic-preview/ 를 엽니다. 태양계에서 시간을 멈추고 기본과 시네마틱을 전환하면 동일 시점의 표면과 빛을 비교할 수 있습니다. 악기는 숫자 키 1~5 또는 터치로 연주합니다. 다운로드한 파이썬 예제는 VPyLab에서 실행할 수 있습니다. 브라우저 시연은 생성된 명령을 재생하므로 코드를 수정하면 위의 Python 명령을 다시 실행해야 합니다.

지구와 달 이미지는 [Three.js r170 지구](https://github.com/mrdoob/three.js/blob/r170/examples/textures/planets/earth_atmos_2048.jpg)와 [달](https://github.com/mrdoob/three.js/blob/r170/examples/textures/planets/moon_1024.jpg)에서 가져왔습니다. 태양 이미지는 이 시연을 위해 절차적으로 생성했습니다.

앱 예제 목록에서 **지구에서 기다리는 혜성**과 **빛으로 연주하는 다섯 음**을 열면 학생 코드를 직접 고쳐 실행할 수 있습니다. 여덟 행성, 혜성의 핵과 두 꼬리, 피아노 녹음 두 세기 및 타악기 합성, 공간 잔향을 포함합니다. 위 독립 시연은 최초 비교 장면을 보존합니다.

### 구현 방향과 검토 기준

- 공통 렌더러에서 자체발광 표면의 무늬, 암석의 요철과 금속 반사를 처리합니다. 발광 표면과 주변을 비추는 광원은 각각 학생이 제어합니다.
- 혜성 핵과 먼지를 태양 중력 아래 이동시키고 먼지의 유효중력을 줄여 복사압을 단순화합니다. 이온 꼬리는 태양 반대 방향을 표시하는 모형입니다. 크기·거리·시간은 수업용 축척입니다.
- 펠트 피아노는 같은 출처의 녹음을 처음 요청할 때 불러오며, 준비 전이나 음역 밖은 합성으로 재생합니다. 마림바·유리종은 서로 다른 배음과 감쇠를 사용합니다. 같은 음을 공간 잔향 유무로 비교할 수 있습니다.
- 지구 표면은 WebGL에서 KTX2(밉맵 11단계)를 우선 사용하고 로드 실패 시 JPEG를 사용합니다. 화면상 구체의 크기에 따라 메시 분할 수도 조정합니다. 연속 프레임이 느려지면 픽셀 비율을 낮추고 회복하면 높입니다. 학교 기기의 프레임 간격, 오디오 지연, 프로젝터에서의 가독성은 현장 검증 항목입니다.
- 독립 HTML의 기존 위젯·입력 제한은 작품 공유 링크와 다릅니다. 독립 HTML은 악기를 배음으로 합성하며 전체 상호작용은 편집기에서 확인하세요.
