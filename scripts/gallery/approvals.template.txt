# VPyLab 갤러리 승인 파일
#
# 이 파일은 VPyLab 갤러리에 실을 작품을 정하는 승인 파일입니다. 이 파일에 승인 줄이 있는 작품만 갤러리에 표시됩니다.
# 한 줄에 하나씩 적으며, 형식에 맞지 않는 줄은 승인으로 처리되지 않습니다.
#
# 줄의 형식 ('#' 뒤는 메모입니다)
#   approve 아이디/저장소    작품 하나를 승인합니다. 저장소 주소(https://github.com/아이디/저장소)를 붙여 넣어도 됩니다.
#   approve @아이디          그 아이디가 올리는 작품을 모두 승인합니다.
#   block 아이디/저장소      작품 하나를 차단합니다. 차단은 승인보다 우선합니다.
#   block @아이디            그 아이디가 올리는 작품을 모두 차단합니다.
#   approve 대신 승인, block 대신 차단으로 적어도 됩니다.
#
# 승인 대기 작품은 같은 브랜치의 PENDING.md에 있습니다.
# 승인 방법: https://github.com/vpylab/vpylab/blob/main/docs/GALLERY_GITHUB.md
