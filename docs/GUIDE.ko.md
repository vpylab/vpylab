# VPyLab 공개판 안내 (교사·학생용)

기준: 2026-11-08, 공개판 https://vpylab.pages.dev

## 1. VPyLab은 무엇인가요

VPyLab은 브라우저에서 파이썬으로 3D 도형·빛·소리를 만드는 학습 도구입니다. 파이썬 실행은 Pyodide가 담당하고, 3D 화면은 Three.js, 소리는 Web Audio를 사용합니다. 코드 문법은 공식 VPython API를 따르며, 소리 명령과 한글 이름은 VPyLab 확장입니다. 프로그램 설치가 필요하지 않습니다.

이 안내는 공개판(https://vpylab.pages.dev) 기준입니다. 공개판에는 VPyLab 서버와 데이터베이스가 없으며 로그인도 없습니다. 로그인·갤러리·팀 프로젝트·GitHub 연동은 수업용 판(VPyLab Classroom) 기능이며 공개판에서는 꺼져 있습니다. 수업용 판 사용법은 [USER_GUIDE_KO.md](USER_GUIDE_KO.md)를 참고합니다.

## 2. 시작하기

준비물은 최신 웹 브라우저와 인터넷 연결뿐이며 계정과 설치는 필요하지 않습니다. 처음 실행할 때 파이썬 엔진 준비에 몇 초가 걸리며, 만들기 화면 오른쪽 위에 준비 상태가 표시됩니다.

1. 브라우저에서 https://vpylab.pages.dev 를 엽니다.
2. 상단 메뉴의 **트레이닝**을 누르고 **기초 코스 시작하기**를 누릅니다.
3. 코드를 고친 뒤 **실행**을 눌러 결과를 확인합니다. 자유롭게 만들 때는 **만들기** 메뉴를 사용합니다.
4. 영어 화면이 필요하면 **더 보기 → 언어 → English**를 고릅니다. 주소 끝에 `?lang=en`을 붙여도 됩니다.

### 교사에게

교사는 학생에게 주소만 안내하면 됩니다. 학급 만들기나 학생 계정 발급은 하지 않습니다. 공개판에는 교사가 앱 안에서 학생 작품을 모아 보는 기능이 없습니다. 작품을 걷을 때 학생이 **HTML 내려받기**로 파일을 만들고, 교사가 그 파일을 받습니다.

## 3. 주요 기능

### 편집기와 실행

만들기 화면은 왼쪽 편집기와 오른쪽 3D 화면 및 콘솔 출력으로 구성됩니다. 휴대폰처럼 좁은 화면에서는 **코드**, **화면**, **출력** 탭으로 나뉩니다. **실행**으로 시작하고 **정지**로 멈추며, 정지는 예약된 소리까지 멈춥니다.

### 자동 완성과 단어 도움

**자동 완성** 버튼이나 Ctrl+Space로 제안을 열 수 있습니다. Tab으로 적용하고 Esc로 닫습니다. `sphere`, `radius` 같은 낯선 영어 단어를 입력하면 그림·뜻·예시가 담긴 작은 카드가 표시됩니다. 문서와 정해진 규칙으로 동작하며 코드를 AI 서비스로 보내지 않습니다.

### 소리

`음표("도4", 0.3)`처럼 음 이름과 길이(초)로 소리를 재생합니다. 영어 이름은 `play_note_and_wait("C4", 0.3)`이며 소리가 끝날 때까지 기다린 뒤 다음 줄을 실행합니다. `play_note()`는 소리를 시작하고 바로 다음 줄로 넘어갑니다. 소리 명령은 VPython에 없는 VPyLab 확장이며 다른 VPython 환경에서는 수정이 필요합니다.

### 트레이닝

기초 코스는 "처음 만드는 빛과 소리"이며 8차시로 구성되고 예상하기·실행하기·한 가지 바꾸기·설명하기 순서로 진행됩니다. 기초 다음 선택 과정은 핵심 연습 6단계(변수, 반복, 조건, 리스트, 빛과 소리 결합, 내 작품)이며 자동 검사가 코드 조건을 확인합니다. 진행 기록은 이 기기의 브라우저에 남습니다. 선택 4차시 "작품 저장과 공유"는 수업용 판의 저장·GitHub 기능 기준이며 공개판에서는 그대로 따라 할 수 없습니다.

### 튜토리얼

짧은 체험 네 가지는 3D 바로 만들기, 빛과 소리 연결하기, 움직임 눈으로 보기, 버튼으로 반응 만들기입니다. 그다음 "만들며 탐구하기"의 작은 프로젝트가 이어지며 점수나 정해진 정답은 없습니다.

### 예제와 문서

만들기 화면 **도구 → 예제**에는 예제 57개가 있으며 분야 8개(우주, 소리, 과학, 미술, 게임, 창작, 수학, 상호작용)로 나뉩니다. **문서** 메뉴에는 항목 97개와 분류 12개(모양 만들기, 3D 객체, 벡터, 씬, 이벤트, 위젯, 그래프, 색, 재질, 소리 등)가 있습니다. 문서는 VPyLab 확장 기능을 따로 표시합니다.

### 대장간

슬라이더로 다시 사용할 3D 오브젝트 하나를 제작하며 캐릭터, 종, 프로젝트 소품, 기본 모양을 만들 수 있습니다. 완성품은 `compound` 하나로 묶입니다. 브라우저의 내 모듈 보관함에 등록되며 코드 복사 또는 `.py` 파일 내려받기가 가능합니다. 공개 등록과 포크는 로그인이 필요해 공개판에서는 사용할 수 없습니다.

### 내보내기

만들기 화면 **도구 → HTML 내려받기**는 코드가 담긴 HTML 파일 하나를 내려받습니다. 브라우저로 열면 작품이 실행됩니다. 열 때 jsDelivr나 unpkg에서 파이썬 엔진과 Three.js를 받으므로 인터넷이 필요합니다.

**도구 → 공유**를 누르면 코드가 주소 안에 담긴 링크가 만들어지고 클립보드에 복사됩니다. 링크를 연 사람의 만들기 화면에 같은 코드가 열리며, 실행 전 내용을 확인하라는 안내가 출력 창에 나옵니다. 공개판에는 갤러리가 없습니다.

| 기능 | 공개판 |
|---|---|
| 실행, 3D 화면, 소리 | 사용 가능 |
| 트레이닝, 튜토리얼, 예제, 문서, 대장간 | 사용 가능 |
| HTML 내려받기, 대장간 `.py` 내려받기 | 사용 가능 |
| 저장, 다른 이름으로 저장, 저장 이력 | 준비 중("저장 기능 준비 중" 안내) |
| 공유 링크 | 사용 가능(코드를 링크 주소에 담음, 임베드 코드 없음) |
| 갤러리, 팀 프로젝트, 로그인 | 사용할 수 없음(수업용 판 기능) |
| 구글 드라이브 저장 | 실험 페이지에서 시험 중 |

## 4. 저장하기

### 지금 상태

공개판 **저장** 버튼(Ctrl/Cmd+S 포함)은 "저장 기능 준비 중" 안내 창을 엽니다. 지금 작품을 보관하는 방법은 **도구 → HTML 내려받기**입니다. 진행 기록과 설정은 이 브라우저에 남고, 연습 중인 코드는 브라우저 탭에 임시로 보관됩니다. 브라우저 데이터를 지우거나 탭을 닫으면 사라질 수 있으며 다른 기기로 옮겨지지 않습니다.

### 구글 드라이브 저장 실험

실험 페이지에서 구글 드라이브 저장을 시험하고 있습니다. 안내 창의 **드라이브 저장 실험 열기** 버튼으로도 열 수 있습니다. 실험 페이지 주소는 https://vpylab.pages.dev/drive-lab 이며, 페이지에는 코드를 넣는 글 상자만 있고 파이썬 실행은 되지 않습니다. 만들기 화면에서 작성한 코드를 복사해 붙여 넣는 방식으로 사용합니다.

1. https://vpylab.pages.dev/drive-lab 을 엽니다.
2. **구글 로그인·드라이브 승인**을 누릅니다.
3. 구글 승인 창에서 계정을 고르고, 드라이브 항목에 체크한 뒤 승인합니다.
4. 코드 상자에 코드를 붙여 넣고 **편집기 내용으로 새 파일**을 누릅니다.
5. 코드를 고친 뒤에는 **저장**을 누릅니다. 이전 내용은 **버전 기록**에서 불러옵니다.

파일은 학생 본인 구글 드라이브의 `VPyLab` 폴더에 저장됩니다. 폴더를 옮기거나 이름을 바꿔도 앱이 같은 폴더를 찾습니다. 교사나 VPyLab 운영자는 학생 파일을 볼 수 없습니다. 이전 내용은 드라이브 버전 기록으로 확인합니다. 두 기기에서 같은 파일을 저장하면 충돌 화면이 표시됩니다.

2026-11-08 개인 gmail 계정으로 시험했습니다. 저장 후 다시 열기, 버전 기록, 토큰 만료 뒤 다시 승인(초안 유지)을 확인했습니다. 연속 저장 30회, 평균 3.0초, 오류 0건이었습니다. 학교 계정 시험은 아직 진행하지 않았습니다.

## 5. 교사가 준비할 것: 학교 구글 계정

이 장은 드라이브 저장 실험을 학교 구글 계정으로 사용할 때만 해당하며 본 앱 사용에는 준비가 필요하지 않습니다. 학교 구글 워크스페이스는 관리자가 외부 앱을 제한할 수 있습니다. 교육용 워크스페이스에서 18세 미만으로 지정된 학생 계정은 관리자가 설정하지 않은 외부 앱을 사용할 수 없습니다. 차단되면 실험 페이지에 관리자 허용이 필요하다는 안내가 표시됩니다.

| 확인할 것 | 내용 |
|---|---|
| 앱 허용 위치 | 관리 콘솔 → 보안 → 액세스 및 데이터 제어 → API 제어 → 앱 액세스 제어 |
| 허용 방법 | OAuth 클라이언트 ID로 앱을 추가하고 **제한됨** 또는 **신뢰함**으로 지정 |
| 드라이브가 제한된 서비스인 학교 | **신뢰함**으로 지정 |
| 18세 미만으로 지정된 학생 계정 | 위 설정이 없으면 사용할 수 없음(교육용 워크스페이스) |
| 학부모 동의 | 법이 요구하는 경우 학교 책임(구글 정책) |
| 테스트 사용자 등록 | 앱이 "테스트 중"인 동안 필요, 최대 100명 |

메뉴 이름은 관리 콘솔 버전에 따라 다를 수 있습니다.

VPyLab의 구글 OAuth 앱은 아직 "테스트 중" 상태이며 구글 검증 전입니다. 테스트 사용자로 등록한 계정만 승인할 수 있으며 구글 기준 최대 100명입니다. 등록하지 않은 계정은 구글 화면에서 `403 access_denied` 오류가 나타납니다. 수업에서 시험하려면 교사가 학생 계정 목록을 VPyLab 운영자에게 보내 등록 요청하며 요청 창구는 [GitHub 이슈](https://github.com/vpylab/vpylab/issues)입니다.

학교가 VPyLab을 직접 배포하고 학교 계정으로 만든 OAuth 클라이언트를 대상 **내부**로 설정할 수 있습니다. 이때 테스트 사용자 등록이 필요하지 않으며 같은 학교 도메인 계정만 사용할 수 있습니다. 클라이언트 ID는 공개값이며 클라이언트 보안 비밀번호는 사용하지 않습니다. 절차는 [DRIVE_LAB.md](DRIVE_LAB.md)를 참고합니다.

## 6. 개인정보

### 공개판

공개판에는 VPyLab 서버와 데이터베이스가 없습니다. 코드는 학생 브라우저 안에서 실행되며 VPyLab이 코드를 저장하지 않습니다. 진행 기록과 설정은 학생 브라우저에만 보관됩니다. 외부로 나가는 요청은 웹 글꼴(Google Fonts, Fontshare)입니다. 파이썬 엔진은 vpylab.pages.dev에서 받고 실패할 때만 jsDelivr나 unpkg를 사용합니다.

### 드라이브 저장 실험

실험 페이지는 구글과 페이지 자신에게만 요청하며 보안 정책이 다른 주소를 차단합니다. 요청 권한은 `openid email profile`(누구인지 확인)과 `drive.file`입니다. `drive.file`은 이 앱이 만든 파일만 다루며 드라이브의 다른 파일은 볼 수 없습니다. 구글 액세스 토큰은 페이지 메모리에만 있고 새로 고침하면 사라집니다. 저장하지 못한 초안은 계정별로 이 브라우저에 남고 14일이 지나면 그 컴퓨터에서 페이지를 다시 열 때 삭제됩니다. 앱 권한 삭제는 **권한 철회** 버튼 또는 <https://myaccount.google.com/connections>에서 합니다.

## 7. 문제가 생겼을 때

### 승인 창이 열리지 않습니다

> 승인 창을 열지 못했습니다. 브라우저의 팝업 차단을 해제하세요.

> 승인 창이 닫혔습니다. 다시 시도하세요.

원인은 브라우저의 팝업 차단입니다. 주소창의 팝업 차단 표시에서 vpylab.pages.dev 팝업을 허용합니다. 그다음 **구글 로그인·드라이브 승인** 버튼을 다시 누릅니다. 승인 창을 직접 닫은 경우에도 버튼을 다시 누르면 됩니다.

### 구글 화면에 `403 access_denied` 오류가 나옵니다

`403 access_denied`의 원인은 테스트 사용자로 등록하지 않은 계정입니다. 교사가 VPyLab 운영자에게 계정 등록을 요청합니다. 등록 뒤 같은 계정으로 다시 승인합니다. 다른 구글 계정으로 로그인한 상태인지도 확인합니다.

### "학교 관리자가 이 앱을 아직 허용하지 않았습니다"가 나옵니다

> 학교 관리자가 이 앱을 아직 허용하지 않았습니다. 정보 담당 선생님께 관리 콘솔에서 VPyLab을 허용해 달라고 요청하세요.

관리자 차단의 원인은 학교 관리 콘솔에서 앱을 허용하지 않은 상태입니다. 정보 담당 교사에게 5장의 설정을 요청합니다. 설정 변경은 반영까지 최대 24시간이 걸릴 수 있습니다.

### 드라이브 권한이 없다는 안내가 나옵니다

> 드라이브 권한이 빠졌습니다. "드라이브 권한 다시 요청"을 누르고, 승인 화면에서 "Google Drive 파일" 항목의 체크 상자를 직접 체크한 뒤 계속을 누르세요.

구글 승인 화면에서 "Google Drive 파일" 항목의 체크 상자는 처음에 비어 있습니다. 체크하지 않고 **계속**을 누르면 로그인만 되고 드라이브 권한은 빠집니다. **드라이브 권한 다시 요청** 버튼을 누른 뒤, 승인 화면에서 그 체크 상자를 직접 체크하고 **계속**을 누릅니다. 수업에서는 승인 전에 이 체크 상자를 먼저 안내하면 시간을 줄일 수 있습니다.

### VPyLab 폴더가 휴지통에 있다는 안내가 나옵니다

> VPyLab 폴더가 드라이브 휴지통에 있습니다. 그대로 두면 안의 파일이 30일 뒤 지워집니다. 아래 "VPyLab 폴더 되살리기"를 누르세요.

학생이 구글 드라이브에서 VPyLab 폴더를 휴지통으로 옮기면 이 안내가 나옵니다. 그대로 두면 폴더 안 파일이 30일 뒤 지워집니다. 앱은 이때 새 파일을 만들지 않고 멈춥니다. **VPyLab 폴더 되살리기** 버튼을 누르면 폴더와 안의 파일이 돌아옵니다. 파일이 목록에 다시 보이기까지 몇 초 걸릴 수 있으며, 보이지 않으면 **목록 새로 고침**을 누릅니다.

### 파일이 휴지통으로 옮겨졌다는 안내가 나옵니다

같은 파일을 다른 탭이나 다른 기기에서 휴지통으로 옮긴 뒤 이 탭에서 저장하면 이 안내가 나옵니다. 휴지통에 있는 파일에는 저장하지 않으며, 편집한 코드는 이 브라우저에 초안으로 남습니다. **편집기 내용으로 새 파일**로 새 파일에 저장하거나, 구글 드라이브 휴지통에서 파일을 되살린 뒤 다시 저장합니다.

### 먼저 저장했다는 충돌 안내가 나옵니다

같은 파일을 두 곳에서 열어 두고 한쪽에서 먼저 저장한 뒤 다른 쪽에서 저장하면 이 안내가 나옵니다. 같은 브라우저의 다른 탭이면 "이 브라우저의 다른 탭(창)에서", 다른 기기면 "다른 기기(기기 이름)가"라고 표시합니다. 세 가지 중 하나를 고릅니다. **내 코드를 사본으로 저장**은 내 코드를 새 파일로 남깁니다. **드라이브 내용 사용**은 내 변경을 버리고 드라이브 내용을 불러옵니다. **내 코드로 덮어쓰기**는 드라이브 내용을 내 코드로 바꿉니다. 고르기 전에는 저장 버튼이 막혀 있어 어느 쪽 내용도 사라지지 않습니다.

### 1시간쯤 지나 저장이 되지 않습니다

> 권한이 만료되었거나 철회되었습니다. 코드는 이 브라우저에 초안으로 남아 있습니다. "다시 승인"을 누르면 이어서 진행합니다.

구글 승인은 약 1시간 유지되며 자동 갱신되지 않습니다. 남은 시간이 5분보다 적으면 **승인 연장** 버튼이 표시됩니다. 만료 뒤 저장하면 안내가 나오고 코드는 이 브라우저에 초안으로 남습니다. **다시 승인**을 누르면 실패한 저장을 이어서 진행합니다. 한 차시가 1시간을 넘거나 쉬는 시간을 지나면 승인 만료가 일어나기 쉽습니다.

### 저장이 느립니다

저장 1회에 약 3초가 걸립니다. 저장 1회는 드라이브 버전 확인, 쓰기, 덮어쓰기 확인의 세 요청으로 이루어집니다. 구글 응답을 기다리는 동안 편집기가 잠기며 기다리는 사이 입력한 내용이 덮이지 않도록 하기 위함입니다. 저장 완료 안내가 나올 때까지 기다리며 버튼을 여러 번 누르지 않습니다.

## 8. 자주 묻는 질문

### 계정이 필요한가요?

공개판은 계정 없이 사용합니다. 구글 계정은 드라이브 저장 실험에서만 필요합니다.

### 학생 코드가 서버로 전송되나요?

공개판에는 코드를 받는 VPyLab 서버가 없습니다. 코드는 브라우저 안에서 실행됩니다. 드라이브 실험에서는 학생 본인 드라이브로만 전송됩니다.

### 교사가 학생 코드를 볼 수 있나요?

공개판에는 교사용 화면이 없습니다. 학생이 **HTML 내려받기**로 받은 파일을 제출하거나 드라이브 파일을 구글 드라이브에서 직접 공유합니다.

### 인터넷 없이 사용할 수 있나요?

공개판은 웹 사이트이므로 인터넷이 필요합니다. 내려받은 HTML 파일도 열 때 인터넷이 필요합니다. 인터넷이 없는 교실용으로는 교사 컴퓨터에서 실행하는 교실 LAN 모드가 별도로 있으며 설명은 [CLASSROOM_LAN_MODE.md](CLASSROOM_LAN_MODE.md)입니다.

### 공용 컴퓨터에서 주의할 점은 무엇인가요?

드라이브 실험의 **로그아웃**을 누르면 그 계정의 초안을 지울지 물으며 공용 컴퓨터에서는 지웁니다. 페이지 로그아웃은 브라우저의 구글 로그인 상태를 바꾸지 않습니다. 로그아웃 뒤 나오는 "구글 계정에서도 로그아웃" 링크로 구글에서도 로그아웃합니다. 하지 않으면 다음 사람이 계정 선택 창에서 앞 사람 계정을 고를 수 있습니다.

### 휴대폰이나 태블릿에서도 되나요?

VPyLab은 브라우저에서 동작하므로 휴대폰이나 태블릿에서도 사용할 수 있습니다. 화면이 좁을 때는 만들기 화면이 코드, 화면, 출력 탭으로 나뉩니다. 브라우저가 지원하면 **더 보기** 메뉴에 앱으로 설치 버튼이 표시됩니다.

### 로그인, 갤러리, 팀 프로젝트는 어디에 있나요?

로그인과 갤러리, 팀 프로젝트는 수업용 판인 VPyLab Classroom의 기능이며 공개판에서는 꺼져 있습니다. 수업용 판 사용법은 [USER_GUIDE_KO.md](USER_GUIDE_KO.md)에 안내되어 있습니다. 공개판은 구글 드라이브 저장을 준비 중입니다.
