# 갤러리 승인 방법 (교사용)

<!-- 문단 문구: docs/reference/solar/github-gallery-261112-solar.md 블록 15~20. 코드 블록과 표는 형식 설명입니다. -->

VPyLab 갤러리는 운영 서버와 DB 없이 GitHub만으로 동작합니다. 학생이 팀 프로젝트 창에서 "갤러리에 올리기"를 누르면 작품이 승인 대기 목록에 들어가고, 교사가 승인 파일에 한 줄을 추가하면 다음 목록 갱신 때 갤러리 화면에 표시됩니다. 승인 전에는 어떤 작품도 갤러리 화면에 표시되지 않습니다. 교사가 하는 일은 모두 GitHub 웹 화면에서 하며, 따로 설치할 프로그램은 없습니다.

갤러리를 처음 켜는 순서(관리자용)는 [DEPLOY_TWO_EDITIONS.md](DEPLOY_TWO_EDITIONS.md)의 "GitHub 연동 갤러리"에 있습니다.

## 1. 승인 대기 작품 확인

승인 대기 작품은 저장소의 gallery-data 브랜치에 있는 PENDING.md 파일에 표로 정리됩니다. 표의 각 줄에는 작품 제목(저장소로 가는 링크), 올린 사람의 GitHub 아이디, 고친 날짜, 승인 파일에 추가할 줄이 있습니다. 승인하기 전에 저장소를 열어 코드(main.py), 실행 화면, 미리보기 그림(thumbnail.jpg), 제목을 확인합니다. 확인할 내용은 수업에 맞는 작품인지, 이름·연락처·얼굴 같은 개인정보나 부적절한 내용이 없는지입니다.

- 승인 대기 목록: <https://github.com/vpylab/vpylab/blob/gallery-data/PENDING.md>
- 승인 파일: <https://github.com/vpylab/vpylab/blob/gallery-data/approvals.txt>

## 2. 승인하기

승인은 gallery-data 브랜치의 approvals.txt 파일에 한 줄을 추가하는 것입니다. GitHub에서 approvals.txt를 열고 연필 모양의 편집 버튼을 누른 뒤 줄을 추가하고, "Commit changes"를 눌러 gallery-data 브랜치에 바로 저장합니다. 승인하는 방법은 두 가지로, 작품 하나만 승인하거나 GitHub 아이디를 승인해 그 학생이 올리는 작품을 모두 싣는 방법이 있습니다. PENDING.md의 마지막 칸에 있는 줄을 복사해 붙여 넣으면 작품 하나가 승인됩니다. 형식에 맞지 않는 줄은 승인으로 처리되지 않으며, 그런 줄은 PENDING.md 아래쪽에 따로 표시됩니다.

```text
# 작품 하나를 승인합니다. 저장소 주소를 붙여 넣어도 됩니다.
approve student-a/vpylab-solar-1a2b3c
approve https://github.com/student-a/vpylab-solar-1a2b3c

# 아이디를 승인합니다. 그 학생이 올리는 작품이 모두 실립니다.
approve @student-b
```

한 줄에 하나씩 적습니다. `#` 뒤는 메모입니다. `approve` 대신 `승인`으로 적어도 됩니다. 아이디와 저장소 이름은 대문자와 소문자를 구분하지 않습니다.

## 3. 갤러리에 표시되는 때

목록은 30분마다 자동으로 갱신됩니다. 바로 반영하려면 저장소의 Actions 탭에서 "Gallery index"를 고르고 "Run workflow"를 누릅니다. 갱신이 끝나면 승인한 작품이 PENDING.md에서 빠지고 갤러리 화면에 표시됩니다. 브라우저가 목록을 잠시 기억하므로 갤러리 화면에는 몇 분 늦게 표시될 수 있습니다.

## 4. 작품 내리기와 차단

승인한 작품을 내리는 방법은 approvals.txt에서 승인 줄을 지우거나 차단 줄을 추가하는 것입니다. 차단은 승인보다 우선하며, 아이디를 승인한 학생의 작품 가운데 하나만 내릴 때 차단 줄을 사용합니다. 차단한 작품은 승인 대기 목록에도 표시되지 않습니다. 학생이 팀 프로젝트 창에서 "갤러리에서 내리기"를 눌러도 내려갑니다. 저장소가 보관되거나 비공개가 되거나 삭제되면 다음 갱신 때 자동으로 빠집니다.

```text
# 작품 하나를 차단합니다.
block student-b/vpylab-prank-9f8e7d

# 아이디를 차단합니다. 그 아이디가 올리는 작품이 모두 실리지 않습니다.
block @someone
```

`block` 대신 `차단`으로 적어도 됩니다.

## 5. 알아 둘 점

승인은 저장소 단위이며, 승인한 뒤 학생이 코드, 제목, 미리보기 그림을 바꾸면 바뀐 내용이 다시 확인 없이 갤러리에 표시됩니다. 아이디를 승인하면 그 학생이 앞으로 올리는 작품도 확인 없이 실리므로, 아이디 승인은 믿을 수 있는 경우에만 사용합니다. 문제가 생긴 작품은 차단 줄로 내릴 수 있습니다. 승인 대기 목록은 공개 저장소에 있어 누구나 볼 수 있습니다. GitHub 계정이 없는 학생은 작품을 올릴 수 없으며, GitHub 계정은 13세 이상만 만들 수 있습니다.

## 파일과 표시

| 이름 | 위치 | 내용 |
|---|---|---|
| `approvals.txt` | gallery-data 브랜치 | 승인 파일. 교사가 고칩니다. |
| `PENDING.md`, `pending.json` | gallery-data 브랜치 | 승인 대기 목록. 자동으로 만들어집니다. |
| `gallery.json` | gallery-data 브랜치 | 승인된 작품 목록. 갤러리 화면이 읽습니다. |
| `vpylab-gallery` | 학생의 저장소 topic | 학생이 갤러리에 올린 저장소에 붙는 표시입니다. |
| `thumbnail.jpg` | 학생의 저장소 | 갤러리 카드의 미리보기 그림입니다(200KB 이하). |
