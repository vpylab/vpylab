# 브리프 — 공유 링크를 실행 화면으로 여는 동작 반영 (2026-11-08)

독자: VPyLab을 처음 사용하는 중·고등학생, 수업을 준비하는 교사
문체: 합쇼체(~합니다), 평서형. 청유("~해 보세요")·구어체 금지. 은유·의인화·과장 금지. 대시(—)로 문장 잇기 금지
맥락: 마크다운 안내문 안의 문단 하나. 제목·표는 따로 들어간다
형식: 출력은 문단 하나. 빈 줄로 나누지 말 것. 목록 기호 금지. "쓰다"(사용 의미) 대신 "사용하다", "단추" 대신 "버튼". KEEP 조각은 굵게 표시까지 그대로

[블록 1] 위치: GUIDE 3장 "작품 내려받기와 공유" 문단 끝 / 역할: 공유 링크 설명
- 사실: **도구 → 공유**를 누르면 코드가 주소 안에 담긴 링크가 만들어지고 클립보드에 복사됨
- 사실: 같은 창에서 **QR 보기**를 누르면 그 링크의 QR 코드가 나옴
- 사실: 링크나 QR 코드로 열면 편집기가 아니라 실행 화면이 먼저 나오고, **클릭하여 시작**을 누르면 작품이 실행됨
- 사실: 왼쪽 위 **코드 보기**를 누르면 만들기 화면에서 같은 코드를 볼 수 있음
- 사실: 공개판에는 갤러리가 없음
- KEEP: **도구 → 공유**, **QR 보기**, **클릭하여 시작**, **코드 보기**
- 분량: 4~5문장
