# 브리프 — 오픈소스 판 편집기의 구글 드라이브 저장: 화면 문구만 (2026-11-09)

독자: VPyLab 공개판(vpylab.pages.dev)을 사용하는 중·고등학생과 교사. 블록 G·H는 학교 정보 담당 교사도 읽음
문체: 합쇼체(~합니다), 평서형. 청유("~해 보세요")·구어체 금지. 은유·의인화·과장 금지. 대시(—)로 문장 잇기 금지
형식: 블록 하나의 출력은 문단 하나. 목록 기호 금지(블록 D·F의 단계 목록은 예외로 "1. " 번호 목록). 굵게 표시 금지. "쓰다"(사용 의미) 대신 "사용하다", "단추" 대신 "버튼". KEEP 조각은 철자 그대로
화면 문구 블록(U로 시작)은 한 줄로, 버튼 이름은 짧게. 확인 창 문구는 끝을 "~할까요?"로 둡니다

공통 사실
- 공개판 만들기 화면의 저장 버튼(Ctrl/Cmd+S 포함)은 코드를 학생 본인 구글 드라이브의 VPyLab 폴더에 저장한다(2026-11-09부터)
- 처음 저장할 때: 저장을 누르면 창이 열린다 → "구글 계정으로 로그인" → 구글 승인 창에서 계정을 고르고 "Google Drive 파일" 체크 상자를 직접 체크한 뒤 계속 → 파일 이름을 적고 "드라이브에 저장"
- 그다음부터는 저장을 누르면 같은 파일에 바로 저장되고 버튼에 "저장됨"이 잠시 표시된다
- 도구 줄의 "내 드라이브" 버튼(파일을 열면 파일 이름이 표시됨)을 누르면 VPyLab 폴더의 파일 목록이 나온다. 파일을 골라 열기, 새 코드로 시작, 로그아웃, 권한 철회를 할 수 있다
- 같은 파일을 다른 탭이나 기기에서 먼저 저장했으면 세 가지 중에서 고른다: 내 코드를 사본으로 저장, 드라이브 내용 불러오기(내 변경은 버림), 내 코드로 덮어쓰기
- 구글 권한은 약 1시간 유지된다. 만료되면 "다시 승인"을 누르면 같은 계정으로 이어서 저장한다. 페이지를 새로 고치면 다시 로그인해야 한다
- 저장하지 못한 변경은 계정별로 이 브라우저에 초안으로 남고, 그 파일을 다시 열 때 불러올지 묻는다. 초안은 14일이 지나면 그 컴퓨터에서 저장 창을 다시 열 때 지워진다
- 이전 내용은 구글 드라이브에서 그 파일의 버전 기록으로 확인한다
- 구글 로그인 스크립트는 저장 창이나 내 드라이브 창을 열 때만 불러온다
- 요청 권한: openid, email, profile(누구인지 확인)과 drive.file. drive.file로는 이 앱이 만든 파일만 볼 수 있고 드라이브의 다른 파일은 볼 수 없다. VPyLab 운영자와 교사는 학생 파일을 볼 수 없다
- 도구 → HTML 내려받기도 그대로 사용할 수 있다. 별도 실험 페이지(vpylab.pages.dev/drive-lab)는 시험용으로 남아 있다

출력 형식: 블록마다 "### U번호" 머리 아래 화면 문구 한 줄만 씁니다. 각 블록의 "/" 뒤 내용은 메모이므로 그대로 옮기지 말고, 화면에 보일 완성된 문장으로 다시 씁니다. 안내·오류 문장은 합쇼체(~습니다, ~하십시오)로 끝냅니다. 예: 메모 "구글 로그인을 준비하고 있다 / 끝에 말줄임표" → "구글 로그인을 준비하고 있습니다…". 메모 "네트워크 연결에 실패했고, 코드는 편집기에 남아 있다" → "네트워크 연결에 실패했습니다. 코드는 편집기에 남아 있습니다." 버튼·제목은 명사형 그대로 둡니다(예: "다시 승인"). 설명이나 따옴표를 붙이지 않습니다. 43개 블록을 모두 씁니다.
