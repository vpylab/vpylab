### 블록 1
VPyLab은 학교 수업용 3D 파이썬 실습실입니다. 학생이 VPython 방식의 파이썬 코드를 작성하면 3D 도형, 빛, 소리를 바로 확인할 수 있습니다. 파이썬은 Pyodide로 브라우저 안에서 실행되며 설치할 프로그램이 없고, 공개판은 계정 없이 사용할 수 있습니다.

### 블록 2
위 코드를 **만들기** 화면에 붙여 넣고 **실행** 버튼을 누르면 결과를 확인할 수 있습니다. 결과는 빛나는 빨간 구, 그 위의 글자, 도·미·솔 세 음으로 나타납니다. `음표`와 `색상` 같은 한글 이름은 VPyLab 확장 기능이며, 영어 이름(`play_note_and_wait`, `color.red`)도 같은 결과를 냅니다. 도형, 벡터, `label`은 공식 VPython API를 따릅니다.

### 블록 3
공개판(vpylab.pages.dev) 편집기에는 아직 저장 기능이 없습니다. **저장** 버튼을 누르면 "저장 기능 준비 중" 안내 창이 표시됩니다. 작품을 보관하려면 만들기 화면의 **도구 → HTML 내려받기**를 사용하십시오.

### 블록 4
공개판에서 **도구 → 공유** 링크 만들기는 아직 동작하지 않습니다. 공유 링크는 수업용 판의 서버가 있어야 만들어집니다.

### 블록 5
구글 드라이브 저장은 별도의 실험 페이지에서 시험 중입니다. 이 기능은 본 편집기 기능이 아닙니다. 실험 페이지는 https://vpylab.pages.dev/drive-lab 에서 확인할 수 있습니다.

### 블록 6
같은 코드를 두 가지 방식으로 빌드할 수 있습니다. 빌드 설정 `VITE_EDITION`으로 판을 선택합니다. 수업용 판(VPyLab Classroom)은 당곡고등학교 수업에서 사용 중이며, 수업용 판 배포는 이 저장소로 옮기는 중이고 아직 `greatsong/vpylab-classroom`에 연결되어 있습니다.

### 블록 7
만들기 화면의 **도구 → 예제**에는 예제 57개와 분야 8개가 있습니다. 자동 완성과 단어 도움은 AI 없이 동작하며, 학생 코드를 AI 서비스로 보내지 않습니다. 언어(한국어·English)와 테마는 **더 보기** 메뉴에서 변경할 수 있습니다.

### 블록 8
공개판에는 VPyLab 서버와 데이터베이스가 없으며, Cloudflare Pages의 정적 파일만 있습니다. 코드는 학생 브라우저 안에서 실행되고 VPyLab이 저장하지 않습니다. 진행 기록, 테마, 언어, 메인 화면 설정은 이 브라우저(localStorage)에 보관되고, 연습 초안은 브라우저 탭(sessionStorage)에 보관됩니다. 브라우저 데이터를 지우면 이 정보가 사라지며 다른 기기로 옮겨지지 않습니다. 외부 요청은 웹 글꼴(Google Fonts, Fontshare)에 대해서만 이루어집니다. 파이썬 엔진은 vpylab.pages.dev에서 받으며, 실패할 때만 jsDelivr나 unpkg를 사용합니다.

### 블록 9
드라이브 실험 페이지는 구글과 페이지 자신에게만 요청하며, 콘텐츠 보안 정책(CSP)이 다른 주소를 차단합니다. 요청 권한은 `openid email profile`과 `drive.file`입니다. `drive.file` 권한으로는 이 앱이 만든 파일만 볼 수 있으며, 드라이브의 다른 파일은 볼 수 없습니다. 파일 위치는 학생 본인 구글 드라이브의 `VPyLab` 폴더이며, VPyLab 운영자는 볼 수 없습니다. 구글 액세스 토큰은 페이지 메모리에만 있고 새로 고침하면 사라집니다. 권한을 삭제하려면 페이지의 **권한 철회** 버튼을 사용하거나 https://myaccount.google.com/connections 에서 처리할 수 있습니다.

### 블록 10
목표는 학생 코드를 학생 본인 구글 드라이브에 두고, 프로젝트는 학생 데이터를 보관하지 않는 것입니다. 실험 페이지는 Google Identity Services 토큰 방식과 `drive.file` 권한을 사용합니다. 실험 페이지에는 코드를 넣는 글 상자만 있으며 파이썬을 실행하지 않습니다.

### 블록 11
2026-11-08에 개인 gmail 계정으로 시험을 진행했습니다. 통과 항목은 저장 후 다시 열기, 드라이브 버전 기록, 토큰 만료 뒤 다시 승인(초안 유지)입니다. 연속 저장 30회를 진행했으며 평균 3.0초, 오류 0건이 기록되었습니다. 네트워크 요청은 구글과 페이지 자신뿐이었습니다.

### 블록 12
구글 OAuth 앱이 "테스트 중" 상태입니다. 테스트 사용자로 등록한 계정만 승인할 수 있으며, 구글 기준 최대 100명까지 가능합니다. 등록하지 않은 계정은 구글 오류 `403 access_denied`가 발생합니다. 학교 구글 워크스페이스 계정은 관리자가 앱을 먼저 허용해야 할 수 있습니다. 액세스 토큰은 약 1시간 지속되며 갱신 토큰은 없습니다. 만료되면 코드를 초안으로 남기고 다시 승인을 요청합니다.

### 블록 13
관리 콘솔의 **보안 → 액세스 및 데이터 제어 → API 제어 → 앱 액세스 제어**에서 OAuth 클라이언트 ID로 앱을 추가합니다. 설정값은 **제한됨** 또는 **신뢰함**이며, 드라이브를 제한된 서비스로 지정한 학교는 **신뢰함**으로 설정합니다. 메뉴 이름은 관리 콘솔 버전에 따라 다를 수 있습니다. 교육용 워크스페이스에서 18세 미만으로 지정된 사용자는 관리자가 설정하지 않은 외부 앱을 사용할 수 없습니다. 법이 요구하는 학부모 동의는 구글 정책상 학교 책임입니다. 앱이 테스트 중인 동안에는 계정을 테스트 사용자로도 등록해야 하며, 요청은 [GitHub 이슈](https://github.com/vpylab/vpylab/issues) 로 할 수 있습니다. 대안으로 학교가 직접 배포하고 대상이 **내부**인 자체 OAuth 클라이언트를 사용하면 테스트 사용자 등록이 불필요하며, 같은 도메인 계정만 사용할 수 있습니다.

### 블록 14
VPyLab은 GlowScript와 VPython 프로젝트가 만든 VPython API를 따릅니다. 그 프로젝트의 사람들은 David Scherer, Bruce Sherwood, Ruth Chabay, John Coady와 기여자들입니다. 기반 라이브러리로 Pyodide, Three.js, Monaco Editor, React를 사용합니다.
