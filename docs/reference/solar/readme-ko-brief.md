[블록 9] 위치: "개인정보" 절, 드라이브 실험 / 역할: 본문
- 사실: 드라이브 실험 페이지는 구글과 페이지 자신에만 요청, 콘텐츠 보안 정책(CSP)이 다른 주소 차단
- 사실: 요청 권한은 `openid email profile`과 `drive.file`
- 사실: `drive.file` 권한으로는 이 앱이 만든 파일만 볼 수 있음, 드라이브의 다른 파일은 볼 수 없음
- 사실: 파일 위치는 학생 본인 구글 드라이브의 `VPyLab` 폴더, VPyLab 운영자는 볼 수 없음
- 사실: 구글 액세스 토큰은 페이지 메모리에만 있고 새로 고침하면 사라짐
- 사실: 권한 삭제는 페이지의 **권한 철회** 버튼 또는 https://myaccount.google.com/connections
- KEEP: `openid email profile`
- KEEP: `drive.file`
- KEEP: `VPyLab`
- KEEP: **권한 철회**
- KEEP: https://myaccount.google.com/connections

[블록 12] 위치: "구글 드라이브 저장 실험" 절, 현재 한계 / 역할: 본문
- 사실: 구글 OAuth 앱이 "테스트 중" 상태
- 사실: 테스트 사용자로 등록한 계정만 승인 가능, 구글 기준 최대 100명
- 사실: 등록하지 않은 계정은 구글 오류 `403 access_denied`
- 사실: 학교 구글 워크스페이스 계정은 관리자가 앱을 먼저 허용해야 할 수 있음
- 사실: 액세스 토큰은 약 1시간, 갱신 토큰 없음
- 사실: 만료되면 코드를 초안으로 남기고 다시 승인을 요청
- KEEP: `403 access_denied`
- 분량: 5문장 안팎

[블록 13] 위치: "학교 정보 담당자" 절, 구글 워크스페이스 / 역할: 본문
- 사실: 관리 콘솔의 **보안 → 액세스 및 데이터 제어 → API 제어 → 앱 액세스 제어**에서 OAuth 클라이언트 ID로 앱 추가
- 사실: 설정값은 **제한됨** 또는 **신뢰함**, 드라이브를 제한된 서비스로 지정한 학교는 **신뢰함**
- 사실: 메뉴 이름은 관리 콘솔 버전에 따라 다름
- 사실: 교육용 워크스페이스에서 18세 미만으로 지정된 사용자는 관리자가 설정하지 않은 외부 앱 사용 불가
- 사실: 법이 요구하는 학부모 동의는 구글 정책상 학교 책임
- 사실: 앱이 테스트 중인 동안에는 계정을 테스트 사용자로도 등록해야 함, 요청은 GitHub 이슈로
- 사실: 대안은 학교가 직접 배포하고 대상이 **내부**인 자체 OAuth 클라이언트 사용, 테스트 사용자 등록 불필요, 같은 도메인 계정만 사용 가능
- KEEP: **보안 → 액세스 및 데이터 제어 → API 제어 → 앱 액세스 제어**
- KEEP: **제한됨**
- KEEP: **신뢰함**
- KEEP: **내부**
- KEEP: [GitHub 이슈](https://github.com/vpylab/vpylab/issues)
