### 블록 1
Cloudflare Pages 프로젝트 `vpylab`은 직접 업로드 방식으로 생성되어 Git 연결로 전환할 수 없습니다. 이 제한 때문에 GitHub Actions 워크플로 `.github/workflows/deploy-pages.yml`을 배포하여 자동 배포를 수행합니다. main 브랜치에 푸시된 커밋의 CI가 모두 통과하면 오픈소스 판이 빌드되어 vpylab.pages.dev에 배포됩니다. 배포 후에는 첫 화면, 개인정보 화면, 만들기 화면, 드라이브 실험 페이지가 정상적으로 열리는지 확인합니다. GitHub 저장소 Actions 탭에서 이 워크플로를 직접 실행할 수도 있습니다.

### 블록 2
저장소 설정의 Actions 비밀값과 변수에는 아래 표의 세 값이 설정되어 있어야 합니다. API 토큰은 Cloudflare Pages에 대한 Edit 권한만 부여하여 생성한 뒤 비밀값으로 등록합니다. 계정 ID와 구글 OAuth 클라이언트 ID는 공개 가능한 값이므로 변수로 등록합니다. 토큰이 없으면 배포 단계가 건너뛰어지고 경고만 남으므로, 포크한 저장소에서는 이 상태가 실패로 표시되지 않습니다.
