# 브리프(내용 가이드) — docs/GUIDE.ko.md (VPyLab 공개판 교사·학생 안내문)

독자: VPyLab을 처음 사용하는 중·고등학생, 수업을 준비하는 교사
문체: 합쇼체(~합니다), 평서형. 청유("~해 보세요")·구어체 금지. 은유·의인화·과장 금지. 대시(—)로 문장 잇기 금지
맥락: 마크다운 안내문. 제목·표·단계 목록·안내 문구 인용은 따로 들어가며, 여기서는 그 사이의 문단만 쓴다
형식: 블록 하나의 출력은 문단 하나. 빈 줄로 나누지 말 것. 목록 기호(-, *)를 쓰지 말 것. 우회 표현 대신 직접 서술. "쓰다"(사용 의미) 대신 "사용하다", "단추" 대신 "버튼". KEEP 조각은 굵게 표시·백틱·링크 모양까지 그대로


다시 쓰기 요청: 아래 다섯 블록만 다시 쓴다. 각 블록의 수정 사유는 다음과 같다.
- 블록 4: "학생이 ... 제출받습니다"는 주어와 서술어가 맞지 않는다. 교사가 학생에게서 파일을 받는다는 뜻이 드러나게 쓴다.
- 블록 14: 실험 페이지 주소 https://vpylab.pages.dev/drive-lab 이 빠졌다. 주소를 원형 그대로 넣는다.
- 블록 22: "승인 창을 직접 닫은 경우에도 버튼을 다시 누르면 된다"는 사실이 빠졌다.
- 블록 26: 마지막 문장에 무엇을 겪기 쉬운지(승인 만료) 대상이 빠졌다.
- 블록 34: USER_GUIDE_KO.md 링크가 드라이브 저장 문장에 붙어 있어 그 문서에 드라이브 저장 설명이 있는 것처럼 읽힌다. 링크는 수업용 판 기능 설명에 붙인다.

[블록 4] 위치: 2장, 교사용 문단 / 역할: 노트
- 사실: 교사는 학생에게 주소만 안내하면 됨, 학급 만들기나 학생 계정 발급 없음
- 사실: 공개판에는 학생 작품을 교사가 앱 안에서 모아 보는 기능 없음
- 사실: 작품을 걷을 때는 학생이 **HTML 내려받기**로 만든 파일을 제출
- KEEP: **HTML 내려받기**
- 분량: 3문장

[블록 14] 위치: 4장, 드라이브 저장 실험 소개 / 역할: 본문
- 사실: 실험 페이지에서 구글 드라이브 저장 시험 중
- 사실: 안내 창의 **드라이브 저장 실험 열기** 버튼으로도 열림
- 사실: 실험 페이지에는 코드를 넣는 글 상자만 있고 파이썬 실행은 안 됨
- 사실: 만들기 화면에서 작성한 코드를 복사해 붙여 넣는 방식
- KEEP: https://vpylab.pages.dev/drive-lab
- KEEP: **드라이브 저장 실험 열기**
- 분량: 3문장 안팎

[블록 22] 위치: 7장 "문제가 생겼을 때", 승인 창이 열리지 않음 / 역할: 본문
- 사실: 원인은 브라우저의 팝업 차단
- 사실: 주소창의 팝업 차단 표시에서 vpylab.pages.dev 팝업 허용
- 사실: 그다음 **구글 로그인·드라이브 승인** 버튼을 다시 누름
- 사실: 승인 창을 직접 닫은 경우에도 버튼을 다시 누르면 됨
- KEEP: **구글 로그인·드라이브 승인**
- 분량: 3문장

[블록 26] 위치: 7장, 토큰 만료 / 역할: 본문
- 사실: 구글 승인은 약 1시간 유지, 자동 갱신 없음
- 사실: 남은 시간이 5분보다 적으면 **승인 연장** 버튼 표시
- 사실: 만료 뒤 저장하면 안내가 나오고 코드는 이 브라우저에 초안으로 남음
- 사실: **다시 승인**을 누르면 실패한 저장을 이어서 진행
- 사실: 한 차시가 1시간을 넘거나 쉬는 시간을 지나면 만나기 쉬움
- KEEP: **승인 연장**
- KEEP: **다시 승인**
- 분량: 4문장 안팎

[블록 34] 위치: 8장, 로그인·갤러리·팀 프로젝트는 어디에 있나요 / 역할: 답변
- 사실: 수업용 판(VPyLab Classroom)의 기능, 공개판에서는 꺼져 있음
- 사실: 공개판은 구글 드라이브 저장을 준비 중
- KEEP: [USER_GUIDE_KO.md](USER_GUIDE_KO.md)
- 분량: 2문장
