# 브리프(내용 가이드) — 공개판 처리방침의 GitHub 팀 프로젝트 구역 (2026-11-12)

독자: 중·고등학생과 교사
문체: 합쇼체(~합니다), 평서형. 청유·구어체 금지. 우회 표현 대신 직접 서술. 대시(—)로 문장을 잇지 않음. 은유 금지. "쓰다" 대신 "사용하다".
맥락: VPyLab 공개판의 개인정보 처리방침. 앞 구역은 구글 드라이브 저장, 이 구역은 선택 기능인 GitHub 팀 프로젝트를 설명. 블록 하나의 출력은 문단 하나, 빈 줄로 나누지 말 것. 제목·머리말 없이 문단만 출력.

[블록 1] 위치: 처리방침 "GitHub 팀 프로젝트" 구역 / 역할: 본문
- 사실: 팀 프로젝트는 선택 기능. 만들기 화면의 팀 프로젝트 창에서 GitHub 계정을 연결할 때만 동작
- 사실: 연결할 때 GitHub에 요청하는 권한은 public_repo와 repo:invite. 공개 저장소 만들기와 저장, 받은 초대 수락에 사용
- 사실: 연결한 뒤 브라우저가 GitHub와 직접 통신. 코드와 기록은 GitHub 저장소에 저장되고 VPyLab 서버에는 저장되지 않음
- 사실: 로그인 확인 코드를 접근 토큰으로 바꾸는 한 번의 요청만 이 사이트의 함수를 거침. 함수는 토큰을 저장하거나 기록하지 않음
- 사실: GitHub 접근 토큰은 브라우저 탭의 저장 공간(sessionStorage)에 있음. 탭을 닫거나 연결을 해제하면 사라짐
- 사실: 프로젝트 저장소는 공개 저장소. 누구나 코드, 저장 기록, 작성자의 GitHub 아이디를 볼 수 있음. 그래서 코드와 기록에 이름, 연락처 같은 개인정보를 넣지 않아야 함
- 사실: 권한은 github.com/settings/applications에서 거둘 수 있음. 저장소는 GitHub에서 직접 지움
- KEEP: public_repo
- KEEP: repo:invite
- KEEP: sessionStorage
- KEEP: github.com/settings/applications
