# 브리프 — 공개판 개인정보 처리방침 1절 수정 (2026-11-09)

독자: VPyLab 공개판(vpylab.pages.dev)을 사용하는 중·고등학생, 교사, 학부모
문체: 합쇼체(~합니다), 평서형. 구어체·은유·과장 금지. 대시(—)로 문장 잇기 금지
형식: 문단 하나. 목록 기호·굵게 표시 금지. "쓰다"(사용 의미) 대신 "사용하다"

[블록 1] 처리방침 소제목 "1. 수집하는 개인정보" 아래 본문 / 역할: 개인정보를 수집하지 않는다는 것과 유일한 저장 예외를 밝힘
- 사실: 공개판은 회원 가입과 로그인을 사용하지 않음
- 사실: VPyLab은 이름, 이메일 같은 개인정보를 수집하지 않음
- 사실: 작성한 코드는 사용자의 브라우저 안에서 실행됨
- 사실: 사용자가 공유를 누를 때만 그 코드와 제목이 저장되며, 자세한 내용은 3절(공유 링크)에 있음
- 분량: 3~4문장
