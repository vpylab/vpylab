## 7. 조립하며 달라진 점

화면에 들어간 문장은 블록 1, 8, 12, 13, 23, 30이 1차 출력, 블록 25가 재요청 2 출력, 나머지가 재요청 1 출력입니다. 문체를 이유로 고친 문장은 없습니다. 아래는 화면 구조 때문에 달라진 부분입니다.

| 블록 | 솔라 출력 | 화면 | 이유 |
|---|---|---|---|
| 3, 4, 10, 16, 17, 20, 24, 26 | 두 줄 | 두 줄을 띄어쓰기 한 칸으로 이어 한 문단으로 표시 | 설계서가 한 줄(문단 하나)을 요청한 블록입니다. 글자는 그대로입니다 |
| 6 | 두 줄 | 순서 아래의 점 목록 두 항목 | 글자는 그대로입니다 |
| 11, 22 | 줄마다 "…버튼을 고르면"으로 시작 | 버튼 견본 아래에 그대로 표시 | 설계서는 버튼 이름을 다시 적지 말라고 했으나 솔라가 문장의 주어로 넣었습니다. 사실이 맞고 견본 없이도 읽히므로 고치지 않았습니다 |
| 28 | 한 줄 | 그림마다 아래에 표시하되, 구글 창 그림 두 장이 이어질 때는 첫 그림에만 표시 | 같은 문장이 연달아 되풀이되지 않게 했습니다 |
| 29 | "창이 영어로 표시되면 같은 곳에 {0}(이)라고 적혀 있습니다." | `{0}`에 그 그림의 다른 언어 표기를 넣음 | 구글 창과 브라우저 창 그림에만 붙습니다. GitHub 창은 영어로만 표시되어 붙이지 않았습니다 |
| 30 다섯째 줄 | "HTML 내려받기"와 "파일 열기 (.py, .html)"의 위치 | 같은 문장을 본떠 "초기 코드로 돌아가기"의 위치를 가리키는 대체 설명을 하나 더 둠 | 공용 컴퓨터 정리 순서의 그림은 표시하는 메뉴 항목이 다릅니다. 클로드가 버튼 이름만 바꿔 넣었습니다 |

화면에 넣은 문장이 솔라 출력과 글자까지 같은지는 스크립트로 대조했습니다(30개 블록 모두 일치).

## 8. 클로드가 정한 짧은 이름표

문장이 아닌 이름표는 솔라에 맡기지 않고 클로드가 정했습니다.

- 펼치기 이름: 버튼을 누르면 일어나는 일 / 그림으로 보기 / 창이 열리지 않을 때 / 세 선택지의 차이 / 두 선택지의 차이 / 구글 로그인 없이 코드를 보관하는 방법 / GitHub 계정이 없을 때 / 프로젝트를 만들면 생기는 것 / 팀원을 초대하는 순서 / 초대가 보이지 않을 때 / 공용 컴퓨터 사용을 마칠 때
- 사용 안내의 펼치기 이름: 파일로 보관하는 순서 / 처음 로그인할 때 구글 창에서 할 일 / 1시간쯤 지나 다시 승인할 때 / 같은 파일을 두 곳에서 저장했을 때 / GitHub 창에서 할 일 / 팀원을 초대하고 수락하는 순서 / 팀원이 먼저 저장했을 때
- 기다리는 동안의 제목: 지금 열린 구글 창에서 할 일 / 지금 열린 GitHub 창에서 할 일
- 그림의 창 이름: 구글 창 / GitHub 창 / 브라우저 창 / VPyLab 만들기 화면
- 그림의 꼬리표: 여기를 누릅니다 / 여기를 체크합니다 / 여기를 고릅니다 / 고른 뒤 여기를 누릅니다 / 보관할 때 / 다시 열 때
- 그림 안의 자리 표시: 내 계정 / 다른 계정
- 캐릭터 이름과 그림 대체 글은 사용 안내의 것을 그대로 사용했습니다(아롱몽, 몽실몽, 초롱몽, 고리몽, 도란몽).

## 9. 그림에 적은 다른 서비스 화면의 글자

`client/src/components/help/external-labels.js`에 모았습니다. 그림에는 VPyLab 화면의 언어와 같은 표기를 적고, 그림 아래에 다른 언어 표기를 함께 알려 줍니다.

| 곳 | 한국어 화면 | 영어 화면 | 근거와 확신 |
|---|---|---|---|
| 구글 권한 화면의 체크 상자 줄 | Google Drive 파일 | Google Drive files | 줄 전체가 아니라 줄에 들어 있는 말만 적었습니다. 한국어는 2026-11-12 확인 내용과 기존 안내 문구(`DRIVE_REASON_TEXT.scope`), 영어는 기존 영어 번역과 같습니다 |
| 구글 권한 화면의 진행 버튼 | 계속 | Continue | 위와 같음 |
| 크롬 팝업 차단 안내의 허용 항목 | 항상 허용 | Always allow | 항목 전체가 아니라 들어 있는 말만 적었습니다. 한국어 표기는 실제 화면에서 다시 확인하지 못했습니다 |
| 크롬 팝업 차단 안내의 닫는 버튼 | 완료 | Done | 실제 화면에서 다시 확인하지 못했습니다 |
| 아이패드·아이폰 설정 | 설정 앱의 Safari 항목, "팝업 차단" | Settings, Safari, "Block Pop-ups" | 문장으로만 안내합니다. 실제 기기에서 확인하지 못했습니다 |
| GitHub 승인 화면의 권한 줄 | Public repositories and repository invites | 같음 | 2026-11-12 확인 내용. GitHub 화면은 영어로만 표시됩니다 |
| GitHub 승인 화면의 초록색 버튼 | Authorize vpylab | 같음 | 2026-11-12 확인 내용 |

구글 창의 계정 목록 그림에는 구글 화면의 글자를 적지 않았습니다("내 계정", "다른 계정"은 자리 표시입니다).
