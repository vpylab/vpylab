# 브리프(내용 가이드) — VPyLab 안내서·리드미·처리방침 보완 (2026-11-09)

독자: 수업에서 VPyLab 공개판(vpylab.pages.dev)을 사용하는 교사와 학생
문체: 합쇼체(~합니다), 평서형. 청유·구어체·우회 표현('~셈입니다', '~하는 이유입니다') 금지. 대시(—)로 문장 잇지 말 것. 은유·의인화 쓰지 말 것.
맥락: 안내서 docs/GUIDE.ko.md의 '내보내기'(공유)와 '문제가 생겼을 때' 절, README.ko.md '지금 상태' 목록, 공개판 개인정보 처리방침 3절(공유 링크)에 들어갈 문단입니다.
형식: 블록 하나의 출력은 문단 하나입니다. 빈 줄로 나누지 마십시오. 화면에 보이는 버튼 이름은 KEEP의 굵은 글씨 그대로 씁니다.

[블록 1] 위치: 안내서 7장 '파일이 휴지통으로 옮겨졌다는 안내가 나옵니다' / 역할: 본문
- 사실: 같은 파일을 다른 탭·다른 기기·구글 드라이브 화면에서 휴지통으로 옮긴 뒤 이 탭에서 저장하면 나오는 안내
- 사실: 휴지통에 있는 파일에는 저장하지 않음
- 사실: 편집한 코드는 이 브라우저에 초안으로 남음
- 사실: 저장 창에 안내와 함께 새 파일로 저장 버튼이 바로 표시됨
- 사실: 해결 방법 두 가지: 새 파일로 저장 버튼으로 지금 코드를 새 파일에 저장, 또는 구글 드라이브 휴지통에서 파일을 되살린 뒤 다시 저장
- KEEP: **새 파일로 저장**
- 분량: 3~4문장
- 연결: 바로 앞에 안내 문구 인용(> 표시)이 따로 놓임. 그 문구를 다시 옮겨 쓰지 말 것

[블록 2] 위치: 안내서 7장 새 항목 '파일을 찾을 수 없다는 안내가 나옵니다' / 역할: 본문
- 사실: 저장하던 파일이 드라이브에서 영구 삭제되었거나, 다른 사람 파일이어서 권한이 사라졌을 때 나오는 안내
- 사실: 휴지통에 있는 경우와 달리 파일을 되살릴 수 없음
- 사실: 저장 창에 안내와 함께 새 파일로 저장 버튼이 표시되고, 누르면 지금 코드가 같은 이름의 새 파일로 VPyLab 폴더에 저장됨
- 사실: 편집한 코드는 이 브라우저에 초안으로 남아 있어 사라지지 않음
- KEEP: **새 파일로 저장**
- 분량: 3~4문장
- 연결: 바로 앞에 안내 문구 인용(> 표시)이 따로 놓임. 그 문구를 다시 옮겨 쓰지 말 것

[블록 3] 위치: 안내서 7장 '저장이 느립니다' / 역할: 본문
- 사실: 저장 한 번에 약 3초
- 사실: 저장 한 번은 드라이브 버전 확인, 쓰기, 덮어쓰기 확인의 세 요청
- 사실: 구글 응답을 기다리는 동안 편집기가 잠김. 기다리는 사이 입력한 내용이 덮이지 않게 하려는 것
- 사실: 저장 중에 버튼이나 Ctrl/Cmd+S를 여러 번 눌러도 저장은 한 번만 일어나고 파일이 두 개 생기지 않음
- 사실: 저장 완료 안내가 나오면 다음 작업을 이어 가면 됨
- KEEP: Ctrl/Cmd+S
- 분량: 4~5문장

[블록 4] 위치: 안내서 '내보내기' 절, 공유 설명 문단 바로 다음 / 역할: 본문
- 사실: 도구 → 공유를 누르는 순간 무작위 주소가 먼저 만들어지고 클립보드에 복사됨
- 사실: 같은 창에서 짧은 이름을 정하면, 쓰이지 않게 된 그 무작위 주소는 저장소에서 지워짐
- 사실: 예외: 이름을 정하기 전에 그 창의 링크 복사, QR 보기, 임베드 코드 복사, 열기 중 하나를 눌렀다면 이미 전했을 수 있어 무작위 주소를 남김
- 사실: 창이 열릴 때 자동으로 복사된 무작위 주소를 이름을 정하기 전에 붙여 넣어 보냈다면, 이름을 정하는 순간 그 주소로는 열리지 않음
- 사실: 그래서 이름을 정할 때는 이름을 정한 뒤에 나온 주소를 공유해야 함. 이름을 정하면 그 주소가 다시 클립보드에 복사됨
- 분량: 4~5문장

[블록 5] 위치: README.ko.md '지금 상태' 목록, 공유 항목 끝에 덧붙일 문장 / 역할: 노트
- 사실: 이름을 정하면 공유 창을 열 때 먼저 만든 무작위 주소는 지워짐
- 사실: 그러므로 이름을 정한 뒤에 나온 주소를 공유해야 함
- 분량: 1~2문장

[블록 6] 위치: 공개판 개인정보 처리방침 3절(공유 링크), '공유한 코드는 삭제 요청이 있을 때까지 보관' 문장 바로 앞 / 역할: 노트
- 사실: 공유 창에서 이름을 정하면, 창을 열 때 먼저 만든 무작위 주소와 그 코드는 바로 지움
- 사실: 지울 때는 그 주소를 만든 브라우저의 수정 열쇠로만 지울 수 있음
- 분량: 1~2문장
