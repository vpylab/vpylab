### 블록 1
도구 → 공유를 누르면 코드와 제목이 Cloudflare D1 저장소에 저장되고 짧은 주소가 만들어집니다. 주소를 아는 사람은 누구나 그 코드를 볼 수 있으므로 코드와 제목에 이름, 연락처 같은 개인정보를 넣지 않아야 합니다. 같은 브라우저에서만 고칠 수 있도록 수정 열쇠가 이 브라우저의 저장 공간(localStorage)에 남고, 저장소에는 열쇠를 변환한 값만 저장됩니다. 짧은 시간에 너무 많이 만드는 것을 막으려고 IP 주소를 변환한 값을 사용하며, IP 주소 자체는 저장하지 않고 변환한 값도 2분 안에 지웁니다. 공유한 코드는 삭제 요청이 있을 때까지 보관하며, 지우려면 GitHub 이슈에 지울 주소만 적으면 됩니다. 저장소가 응답하지 않을 때는 코드를 압축해 링크 주소 안에 담은 긴 링크를 대신 만들며, 이때는 저장소에 저장하지 않습니다.

### 블록 13
도구 → 공유를 누르면 짧은 주소(예: vpylab.pages.dev/s/k7x2p9)가 만들어지고 클립보드에 복사됩니다. 같은 창 아래 "짧은 이름 정하기" 칸에 이름을 넣고 "이 이름으로 만들기"를 누르면 vpylab.pages.dev/s/정한이름 주소가 됩니다. 규칙은 영어 소문자, 숫자, 하이픈(-) 3~30자이고 먼저 정한 사람이 사용합니다. 같은 브라우저에서 같은 이름을 다시 정하면 그 주소의 코드가 지금 코드로 바뀝니다. 다른 브라우저나 기기에서는 바꿀 수 없습니다. 같은 창에서 QR 보기를 누르면 그 주소의 QR 코드가 나오고, 임베드 코드 복사로 다른 웹페이지에 작품을 넣을 수 있습니다. 주소나 QR 코드로 열면 편집기가 아니라 실행 화면이 먼저 나오고, 클릭하여 시작을 누르면 작품이 실행됩니다. 왼쪽 위 코드 보기를 누르면 만들기 화면에서 같은 코드를 볼 수 있습니다. 주소를 아는 사람은 누구나 코드를 볼 수 있으므로 개인정보를 넣지 않아야 하며, 공개판에는 갤러리가 없습니다.

### 블록 14
공개판에서도 도구 → 공유로 짧은 주소를 만들 수 있습니다. 이름을 정하면 vpylab.pages.dev/s/정한이름이 되고, 정하지 않으면 무작위 6자가 붙습니다. 주소나 QR 코드로 열면 실행 화면이 먼저 나오며, 임베드 코드도 제공합니다. 코드와 제목만 Cloudflare D1에 저장하며 로그인은 필요 없습니다.

### 블록 15
공개판에는 계정이나 로그인이 없고, VPyLab이 개인정보를 저장하는 서버나 데이터베이스도 없습니다. 저장소는 공유 주소용 Cloudflare D1 하나뿐이며, 공유를 누를 때 코드와 제목만 저장됩니다. 코드는 학생 브라우저 안에서 실행됩니다. 진행 기록, 테마, 언어, 메인 화면 설정은 이 브라우저(localStorage)에, 연습 초안은 브라우저 탭(sessionStorage)에 보관됩니다. 브라우저 데이터를 지우면 사라지며 다른 기기로 옮겨지지 않습니다. 외부 요청은 웹 글꼴(Google Fonts, Fontshare)을 받을 때 이루어집니다. 파이썬 엔진은 vpylab.pages.dev에서 받으며, 실패할 때만 jsDelivr나 unpkg를 사용합니다.

### 블록 16
오픈소스 판의 공유 주소는 Cloudflare Pages 함수(functions/api/share/)가 만들고 읽으며, 규칙은 cloudflare/share-core.js 한 곳에 있습니다. 저장소는 D1 데이터베이스 vpylab-shares(아시아·태평양 지역)이고, wrangler.toml에서 DB라는 이름으로 연결합니다. 따로 운영하는 서버는 없고, 정적 파일과 함께 배포됩니다. IP 주소를 변환할 때 섞는 비밀값 SHARE_SALT는 Pages 비밀값으로 넣어 둡니다. 저장소가 응답하지 않으면 앱은 코드를 주소에 담은 링크(#code=)로 대신하므로 공유가 막히지 않습니다. 수업용 판은 지금처럼 Railway 서버가 Supabase에 무작위 8자 주소로 저장하며, 이름 정하기는 아직 지원하지 않습니다.

### 블록 17
표 구조는 cloudflare/migrations/ 폴더에 있고, 바꾼 뒤에는 원격 데이터베이스에 반영하는 명령을 실행합니다. 부적절한 공유 주소나 삭제 요청이 들어온 주소는 지우는 명령으로 처리하며, 명령은 Cloudflare 계정에 로그인한 컴퓨터에서 실행합니다. 무료 사용량은 하루에 쓰기 10만 건, 읽기 500만 건이며 학교 수업 규모로는 비용이 들지 않습니다.
