### 블록 1
팀 프로젝트는 선택 기능이며 만들기 화면의 팀 프로젝트 창에서 GitHub 계정을 연결할 때만 동작합니다. 연결할 때 GitHub에 요청하는 권한은 public_repo와 repo:invite이며 공개 저장소를 만들고 저장하고 받은 초대를 수락하는 데 사용합니다. 연결한 뒤에는 브라우저가 GitHub와 직접 통신하며 코드와 기록은 GitHub 저장소에 저장되고 VPyLab 서버에는 저장되지 않습니다. 로그인 확인 코드를 접근 토큰으로 바꾸는 한 번의 요청만 이 사이트의 함수를 거치며 그 함수는 토큰을 저장하거나 기록하지 않습니다. GitHub 접근 토큰은 브라우저 탭의 저장 공간인 sessionStorage에 있으며 탭을 닫거나 연결을 해제하면 사라집니다. 프로젝트 저장소는 공개 저장소이므로 누구나 코드, 저장 기록, 작성자의 GitHub 아이디를 볼 수 있으며 따라서 코드와 기록에 이름, 연락처 같은 개인정보를 넣지 않아야 합니다. 권한은 github.com/settings/applications에서 거둘 수 있고 저장소는 GitHub에서 직접 지웁니다.
