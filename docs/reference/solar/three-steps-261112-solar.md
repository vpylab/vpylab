### 블록 1
이 브라우저의 저장 공간(localStorage)에는 학습 진행 상황, 화면 테마, 언어, 홈 설정이 남습니다. 만들기 화면에서 작성하던 코드도 같은 저장 공간에 남으며, 이어서 작업하기 위한 목적입니다. 그 코드는 14일이 지나면 만들기 화면을 다시 열 때 지워집니다. 학습 자료에서 연습 중인 초안은 브라우저 탭의 저장 공간(sessionStorage)에 남습니다. 이 정보는 VPyLab으로 전송되지 않으며, 브라우저 데이터를 지우면 사라지고 다른 기기로 옮겨지지 않습니다. 공용 컴퓨터에서는 도구 메뉴의 초기 코드로 돌아가기를 누르면 만들기 화면에 남은 코드가 지워집니다.

### 블록 2
구글 로그인 스크립트를 불러오는 때는 저장 창이나 내 드라이브 창을 열 때, 그리고 이 탭에 드라이브 연결이 남아 있을 때뿐입니다. 구글 접근 토큰의 위치는 브라우저 탭의 저장 공간(sessionStorage)이며, 새로 고침해도 유지되지만 탭을 닫거나 로그아웃하면 사라집니다. 토큰은 약 1시간 뒤 만료되며, 만료 뒤에 저장하면 같은 계정으로 다시 승인받습니다.

### 블록 3
만들기 화면의 저장은 구글 로그인으로 openid, email, profile, drive.file 권한을 요청합니다. 코드는 사용자 본인의 구글 드라이브 VPyLab 폴더에 저장됩니다. 이 저장에는 VPyLab 계정이 필요 없으며, 저장한 파일과 구글 계정 정보는 VPyLab 서버로 전송되지 않습니다. drive.file 권한으로는 이 앱이 만든 파일만 볼 수 있고 드라이브의 다른 파일은 볼 수 없습니다. 구글 접근 토큰은 브라우저 탭의 저장 공간(sessionStorage)에 있으며, 탭을 닫거나 로그아웃하면 사라집니다. 만들기 화면에서 작성하던 코드와 저장하지 못한 초안은 이 브라우저의 저장 공간(localStorage)에 남고, 14일이 지나면 지워집니다. 팀 프로젝트의 코드와 기록은 기존과 같이 Supabase와 GitHub 저장소에 저장됩니다.

### 블록 4
코드 실행과 내 작품 저장에는 로그인이 필요 없습니다. 내 작품은 만들기 화면의 "저장"으로 구글 드라이브에 저장됩니다. 팀 프로젝트는 GitHub 계정으로 로그인해 사용합니다.

### 블록 5
팀 프로젝트는 GitHub 계정으로 로그인해 사용합니다. 혼자 만드는 작품은 로그인 없이 만들 수 있고 구글 드라이브에 저장할 수 있습니다.
