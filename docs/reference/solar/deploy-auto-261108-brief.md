# 브리프 — 오픈소스 판 자동 배포 설명 (2026-11-08)

독자: VPyLab 저장소를 관리하는 교사·개발자
문체: 합쇼체(~합니다), 평서형. 청유·구어체 금지. 은유·과장 금지. 대시(—)로 문장 잇기 금지
형식: 블록 하나의 출력은 문단 하나. 빈 줄 금지. 목록 기호 금지. "쓰다"(사용 의미) 대신 "사용하다". KEEP 조각은 백틱까지 그대로

[블록 1] 위치: 개발 문서 "Cloudflare Pages 설정" 절의 첫 문단 / 역할: 자동 배포가 어떻게 이루어지는지
- 사실: Cloudflare Pages 프로젝트 `vpylab`은 직접 업로드 방식으로 만들어서 나중에 Git 연결로 바꿀 수 없음
- 사실: 그래서 GitHub Actions 워크플로 `.github/workflows/deploy-pages.yml`이 배포함
- 사실: main에 올라온 커밋의 CI가 모두 통과하면 오픈소스 판을 빌드해 vpylab.pages.dev에 올림
- 사실: 배포 뒤 첫 화면, 개인정보 화면, 만들기 화면, 드라이브 실험 페이지가 열리는지 확인함
- 사실: Actions 탭에서 이 워크플로를 직접 실행할 수도 있음
- KEEP: `vpylab`, `.github/workflows/deploy-pages.yml`
- 분량: 4~5문장

[블록 2] 위치: 같은 절, 저장소 설정 표 바로 앞 / 역할: 필요한 설정
- 사실: 저장소 설정의 Actions 비밀값과 변수에 아래 표의 세 값이 있어야 함
- 사실: API 토큰은 "Cloudflare Pages: Edit" 권한만 주어 만들고 비밀값으로 넣음
- 사실: 계정 ID와 구글 OAuth 클라이언트 ID는 공개해도 되는 값이라 변수로 넣음
- 사실: 토큰이 없으면 배포 단계를 건너뛰고 경고만 남기므로 포크한 저장소에서는 실패로 표시되지 않음
- 분량: 3~4문장
