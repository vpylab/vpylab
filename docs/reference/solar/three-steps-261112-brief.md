# 브리프(내용 가이드) — VPyLab 세 단계 전환 안내 문구 (2026-11-12)

독자: 중·고등학생과 교사(개인정보 처리방침, 로그인 창)
문체: 합쇼체(~합니다), 평서형. 청유·구어체 금지. 우회 표현 대신 직접 서술. 대시(—)로 문장을 잇지 않음. 은유 금지. "쓰다" 대신 "사용하다".
맥락: VPyLab은 브라우저에서 파이썬으로 3D 작품을 만드는 교육용 앱. 로그인 없이 시작하고, 저장은 학생 본인의 구글 드라이브, 팀 프로젝트만 GitHub를 사용하도록 바뀜. 블록 하나의 출력은 문단 하나, 빈 줄로 나누지 말 것. 제목·머리말 없이 문단만 출력.

[블록 1] 위치: 공개판 처리방침 2절 "브라우저에 남는 정보" / 역할: 본문
- 사실: 이 브라우저의 저장 공간(localStorage)에 남는 것: 학습 진행 상황, 화면 테마, 언어, 홈 설정
- 사실: 만들기 화면에서 작성하던 코드도 같은 저장 공간에 남음. 목적은 이어서 작업하기
- 사실: 그 코드는 14일이 지나면 만들기 화면을 다시 열 때 지워짐
- 사실: 학습 자료에서 연습 중인 초안은 브라우저 탭의 저장 공간(sessionStorage)에 남음
- 사실: 이 정보는 VPyLab으로 전송되지 않음. 브라우저 데이터를 지우면 사라짐. 다른 기기로 옮겨지지 않음
- 사실: 공용 컴퓨터에서는 도구 메뉴의 초기 코드로 돌아가기를 누르면 만들기 화면에 남은 코드가 지워짐
- KEEP: localStorage
- KEEP: sessionStorage
- KEEP: 초기 코드로 돌아가기
- 분량: 5문장 안팎

[블록 2] 위치: 공개판 처리방침 5절 "구글 드라이브 저장"의 중간 세 문장(앞 문장은 드라이브 권한 설명, 뒤 문장은 초안 보관 설명) / 역할: 본문
- 사실: 구글 로그인 스크립트를 불러오는 때는 두 경우뿐. 저장 창이나 내 드라이브 창을 열 때, 이 탭에 드라이브 연결이 남아 있을 때
- 사실: 구글 접근 토큰의 위치는 브라우저 탭의 저장 공간(sessionStorage). 새로 고침해도 유지. 탭을 닫거나 로그아웃하면 사라짐
- 사실: 토큰은 약 1시간 뒤 만료. 만료 뒤에 저장하면 같은 계정으로 다시 승인받음
- KEEP: sessionStorage
- 분량: 3문장

[블록 3] 위치: 수업용 판 처리방침의 새 구역 "구글 드라이브 저장과 브라우저에 남는 정보" / 역할: 본문
- 사실: 만들기 화면의 저장은 구글 로그인으로 openid, email, profile, drive.file 권한을 요청
- 사실: 코드는 사용자 본인의 구글 드라이브 VPyLab 폴더에 저장
- 사실: 이 저장에는 VPyLab 계정이 필요 없음. 저장한 파일과 구글 계정 정보는 VPyLab 서버로 전송되지 않음
- 사실: drive.file 권한으로는 이 앱이 만든 파일만 볼 수 있음. 드라이브의 다른 파일은 볼 수 없음
- 사실: 구글 접근 토큰은 브라우저 탭의 저장 공간(sessionStorage)에 있음. 탭을 닫거나 로그아웃하면 사라짐
- 사실: 만들기 화면에서 작성하던 코드와 저장하지 못한 초안은 이 브라우저의 저장 공간(localStorage)에 남음. 14일이 지나면 지워짐
- 사실: 팀 프로젝트의 코드와 기록은 기존과 같이 Supabase와 GitHub 저장소에 저장
- KEEP: openid, email, profile, drive.file
- KEEP: sessionStorage
- KEEP: localStorage
- KEEP: Supabase
- 분량: 7문장 안팎

[블록 4] 위치: 로그인 창(제목 "팀 프로젝트 로그인") 아래 설명 / 역할: 안내
- 사실: 코드 실행과 내 작품 저장에는 로그인이 필요 없음
- 사실: 내 작품은 만들기 화면의 "저장"으로 구글 드라이브에 저장
- 사실: 팀 프로젝트는 GitHub 계정으로 로그인해 사용
- KEEP: "저장"
- 분량: 3문장, 짧게

[블록 5] 위치: 팀 프로젝트 창, 로그인하지 않았을 때의 안내 / 역할: 안내
- 사실: 팀 프로젝트는 GitHub 계정으로 로그인해 사용
- 사실: 혼자 만드는 작품은 로그인 없이 만들 수 있고 구글 드라이브에 저장할 수 있음
- 분량: 2문장, 짧게
