아래는 당신이 쓴 문단입니다. 세 번째 문장 "예외로는 이름을 정하기 전에 ... 무작위 주소를 남깁니다."는 주어와 서술어가 맞지 않는 비문입니다. 이 문장만 바르게 고쳐서 문단 전체를 다시 출력하십시오. 다른 문장의 사실과 순서는 바꾸지 마십시오. 합쇼체를 유지하고 우회 표현 없이 직접 서술하십시오. 문단 하나만 출력하고 설명은 붙이지 마십시오.

도구 → 공유를 누르는 순간 무작위 주소가 먼저 만들어지고 클립보드에 복사됩니다. 같은 창에서 짧은 이름을 정하면, 쓰이지 않게 된 그 무작위 주소는 저장소에서 지워집니다. 예외로는 이름을 정하기 전에 그 창의 링크 복사, QR 보기, 임베드 코드 복사, 열기 중 하나를 눌렀다면 이미 전했을 수 있어 무작위 주소를 남깁니다. 창이 열릴 때 자동으로 복사된 무작위 주소를 이름을 정하기 전에 붙여 넣어 보냈다면, 이름을 정하는 순간 그 주소로는 열리지 않습니다. 그래서 이름을 정할 때는 이름을 정한 뒤에 나온 주소를 공유해야 합니다. 이름을 정하면 그 주소가 다시 클립보드에 복사됩니다.
