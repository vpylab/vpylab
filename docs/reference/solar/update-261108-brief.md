# 브리프 — 안내문·README 보완 (2026-11-08 안정성 시험 반영)

독자: VPyLab을 처음 사용하는 중·고등학생, 수업을 준비하는 교사
문체: 합쇼체(~합니다), 평서형. 청유("~해 보세요")·구어체 금지. 은유·의인화·과장 금지. 대시(—)로 문장 잇기 금지
맥락: 마크다운 안내문 안의 문단 하나씩. 제목·표는 따로 들어간다
형식: 블록 하나의 출력은 문단 하나. 빈 줄로 나누지 말 것. 목록 기호 금지. "쓰다"(사용 의미) 대신 "사용하다", "단추" 대신 "버튼". KEEP 조각은 굵게 표시·백틱까지 그대로

[블록 1] 위치: README.ko "지금 상태" 목록 안의 한 항목(목록 기호는 붙이지 않음) / 역할: 공유 링크 안내
- 사실: 공개판에서도 **도구 → 공유**로 링크를 만들 수 있음
- 사실: 서버에 저장하지 않고 코드를 압축해 링크 주소 안에 담음
- 사실: 그래서 코드가 길면 링크도 길어지고, 코드가 아주 길면 QR 코드를 만들지 못할 수 있음
- 사실: 웹페이지에 넣는 임베드 코드는 공개판에서 제공하지 않음
- KEEP: **도구 → 공유**
- 분량: 3문장

[블록 2] 위치: GUIDE 3장 "작품 내려받기와 공유" 문단 끝 / 역할: 공유 링크 설명
- 사실: **도구 → 공유**를 누르면 코드가 주소 안에 담긴 링크가 만들어지고 클립보드에 복사됨
- 사실: 링크를 연 사람의 만들기 화면에 같은 코드가 열리고, 실행 전 내용을 확인하라는 안내가 출력 창에 나옴
- 사실: 공개판에는 갤러리가 없음
- KEEP: **도구 → 공유**
- 분량: 3문장

[블록 3] 위치: GUIDE 7장 "드라이브 권한이 빠졌다는 안내가 나옵니다" / 역할: 원인과 해결
- 사실: 구글 승인 화면에서 "Google Drive 파일" 항목의 체크 상자는 처음에 비어 있음
- 사실: 체크하지 않고 **계속**을 누르면 로그인만 되고 드라이브 권한은 빠짐
- 사실: **드라이브 권한 다시 요청** 버튼을 누른 뒤, 승인 화면에서 그 체크 상자를 직접 체크하고 **계속**을 누름
- 사실: 수업에서는 승인 전에 이 체크 상자를 먼저 안내하면 시간을 줄일 수 있음
- KEEP: **계속**, **드라이브 권한 다시 요청**
- 분량: 4문장

[블록 4] 위치: GUIDE 7장 새 항목 "VPyLab 폴더가 휴지통에 있다는 안내가 나옵니다" / 역할: 원인과 해결
- 사실: 학생이 구글 드라이브에서 VPyLab 폴더를 휴지통으로 옮기면 나오는 안내
- 사실: 그대로 두면 폴더 안 파일이 30일 뒤 지워짐
- 사실: 앱은 이때 새 파일을 만들지 않고 멈춤
- 사실: **VPyLab 폴더 되살리기** 버튼을 누르면 폴더와 안의 파일이 돌아옴
- 사실: 파일이 목록에 다시 보이기까지 몇 초 걸릴 수 있으며, 보이지 않으면 **목록 새로 고침**을 누름
- KEEP: **VPyLab 폴더 되살리기**, **목록 새로 고침**
- 분량: 4~5문장

[블록 5] 위치: GUIDE 7장 새 항목 "파일이 휴지통으로 옮겨졌다는 안내가 나옵니다" / 역할: 원인과 해결
- 사실: 같은 파일을 다른 탭이나 다른 기기에서 휴지통으로 옮긴 뒤 이 탭에서 저장하면 나오는 안내
- 사실: 휴지통에 있는 파일에는 저장하지 않으며, 편집한 코드는 이 브라우저에 초안으로 남음
- 사실: **편집기 내용으로 새 파일**로 새 파일에 저장하거나, 구글 드라이브 휴지통에서 파일을 되살린 뒤 다시 저장함
- KEEP: **편집기 내용으로 새 파일**
- 분량: 3문장

[블록 6] 위치: GUIDE 7장 새 항목 "먼저 저장했다는 충돌 안내가 나옵니다" / 역할: 원인과 해결
- 사실: 같은 파일을 두 곳에서 열어 두고 한쪽에서 먼저 저장한 뒤 다른 쪽에서 저장하면 나오는 안내
- 사실: 같은 브라우저의 다른 탭이면 "이 브라우저의 다른 탭(창)에서", 다른 기기면 "다른 기기(기기 이름)가"라고 표시
- 사실: 세 가지 중 하나를 고름. **내 코드를 사본으로 저장**은 내 코드를 새 파일로 남김. **드라이브 내용 사용**은 내 변경을 버리고 드라이브 내용을 불러옴. **내 코드로 덮어쓰기**는 드라이브 내용을 내 코드로 바꿈
- 사실: 고르기 전에는 저장 버튼이 막혀 있어 어느 쪽 내용도 그냥 사라지지 않음
- KEEP: **내 코드를 사본으로 저장**, **드라이브 내용 사용**, **내 코드로 덮어쓰기**
- 분량: 4~5문장

[블록 7] 위치: README.ko 드라이브 저장 실험 단락에 이어지는 문단 / 역할: 학교 계정 시험 결과
- 사실: 2026년 11월 8일 시험에서 당곡고(danggok.hs.kr) 교사 계정은 학교 관리자 설정 없이 승인되었고 저장도 되었음
- 사실: 학생 계정은 학교마다 관리자 정책이 달라 아직 확인하지 않았음
- 분량: 2문장
