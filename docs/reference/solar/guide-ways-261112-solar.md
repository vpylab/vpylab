````markdown
도구 메뉴의 "공유"를 누르면 작품 링크가 만들어집니다. 링크를 보관하거나 다른 사람에게 보낼 수 있습니다. 링크를 저장 용도로 사용해도 됩니다.
"HTML 내려받기"로 받은 파일은 VPyLab 없이 혼자 실행됩니다. 인터넷 연결이 필요합니다. 도구 메뉴의 "파일 열기 (.py, .html)"로 VPyLab에 다시 불러올 수 있습니다. "파이썬 파일(.py) 내려받기"도 있습니다.

### 블록 5
왜 그럴까? 더 살펴보자. 코드의 숫자를 하나 바꾸고 다시 실행하면 무엇이 달라지는지 확인할 수 있어.

### 블록 6
조금 해 보고 골라도 돼. 로그인 없이 먼저 만들고, 저장 방법은 나중에 정해도 돼.

### 블록 7
이것도 한번 살펴볼까? "공유"로 만든 링크를 친구에게 보내면 친구도 바로 실행해 볼 수 있어.

### 블록 8
다른 컴퓨터에서도 이어서 작업하려면 내 구글 드라이브에 저장합니다. 이는 1번 방법에 저장을 더하는 것이며 만드는 방법은 그대로입니다.

### 블록 9
만들기 화면의 "저장"(Ctrl/Cmd+S)을 누르고 구글 계정으로 로그인하면 내 구글 드라이브의 VPyLab 폴더에 저장됩니다.
"내 드라이브" 버튼으로 저장한 작품을 다른 컴퓨터에서도 엽니다.
VPyLab은 이 앱이 만든 파일만 볼 수 있습니다. 운영자는 학생 코드를 보관하지 않습니다.
구글 연결은 약 1시간마다 다시 승인받습니다. 그때 "저장"을 누르면 승인 창이 잠깐 열렸다 닫힙니다. 탭을 닫으면 연결이 끊깁니다.

### 블록 10
이 느낌, 어떻게 담아 볼까? 마음에 든 작품을 내 드라이브에 저장해 두면 다음에 이어서 고칠 수 있어.

### 블록 11
구글 드라이브는 내가 만든 파일만 열 수 있으므로, 여러 사람이 함께 만드는 작품은 GitHub에 저장합니다.

### 블록 12
만들기 화면의 "팀 프로젝트" 버튼에서 GitHub 계정을 연결합니다. 13세 이상이 만들 수 있는 GitHub 계정이 필요합니다. 원하는 사람만 사용하는 선택 기능입니다.
프로젝트 하나가 GitHub 저장소 하나입니다. 저장할 때마다 커밋이 남아 누가 언제 바꿨는지 확인합니다.
팀원을 GitHub 아이디로 초대합니다.
이 사이트에서는 팀원이 초대 코드로 프로젝트에 합류합니다.
팀원이 먼저 저장했으면 최신 코드를 가져온 뒤 저장합니다.

### 블록 13
이 둘을 함께 해 보면? 내 코드와 친구 코드를 한 프로젝트에 모으면 혼자서는 만들기 어려운 작품이 돼.

### 블록 14
너는 어떻게 생각해? 같은 부분을 고치기 전에 누가 먼저 저장할지 팀원과 정하자.

### 블록 15
직접 만들어 볼까? "팀 프로젝트"에서 새 프로젝트를 하나 만들면 그것이 팀의 저장소가 돼.

### 블록 16
이 사이트에는 구글 드라이브 저장이 설정되어 있지 않습니다. 1번 방법의 링크와 파일로 보관합니다.
이 사이트에는 팀 프로젝트가 설정되어 있지 않습니다.
팀으로 함께 만들며 배우는 방법은 이 화면 아래쪽의 팀 프로젝트 안내에 이어집니다.
아래쪽 팀 프로젝트 안내에 나오는 초대 코드는 수업용 사이트에서 사용하는 방식입니다.
````

## 3. 재요청 (블록 1, 블록 12)

재요청한 이유는 두 가지입니다. 블록 1은 둘째 문장의 주어와 서술어가 맞지 않았습니다. 블록 12 둘째 줄은 설계서의 사실이 지나쳤습니다. 받은 사실은 "저장하면 커밋이 남는다"까지인데 클로드가 설계서에 "누가 언제 바꿨는지 확인함"을 덧붙였고, 화면에서 확인하지 못한 내용이라 사실 줄을 바로잡아 다시 쓰게 했습니다. 머리말(독자·맥락·문체·형식·금지·버튼 이름)은 1차 설계서와 같습니다.

## 5. 조립하며 달라진 점

화면에 들어간 문장은 블록 1과 블록 12는 재요청 출력, 나머지는 1차 출력입니다. 문체를 이유로 고친 문장은 없습니다. 아래는 사실과 화면 구조 때문에 달라진 부분입니다.

|---|---|---|---|
| 12 첫째 줄, 15 | "팀 프로젝트" | 버튼 이름 자리를 `{0}`으로 두고 배포에 맞는 이름을 넣음 | 구글 드라이브 저장이 없는 배포의 만들기 화면에서는 같은 버튼의 이름이 "프로젝트"입니다(`Sandbox.jsx`). 구글 드라이브 저장이 있는 배포에서는 솔라 출력과 글자가 같습니다 |

## 6. 클로드가 정한 짧은 이름표

문장이 아닌 이름표는 솔라에 맡기지 않고 클로드가 정했습니다. 구역 제목과 단계 사이의 말은 사용자 요청의 표현을 따랐습니다.

- 구역 제목: 세 가지 방법으로 만들기
- 단계 위의 말: 먼저 / 저장이 필요하면 / 함께 만들 때
- 단계 제목: 혼자 만들기 / 구글 드라이브에 저장하기 / 팀으로 만들기
- 단계 꼬리표: 로그인 없이 / 구글 계정 / GitHub 계정 · 선택 기능
- 버튼 줄의 이름: 누르는 곳
- 캐릭터 이름과 그림 대체 글: 두근몽(씨앗 캐릭터), 초롱몽(손전등 캐릭터), 몽실몽(구름 캐릭터), 살랑몽(연 캐릭터), 아롱몽(스케치북 캐릭터), 고리몽(이어진 퍼즐 캐릭터), 도란몽(말풍선 캐릭터), 뚝딱몽(공구상자 캐릭터)

영어 번역은 클로드가 썼고 `client/src/i18n/catalogs/en-ui-text.json`에 합쳤습니다.
