# 브리프 — 구글 앱 프로덕션 게시 반영과 다른 학교 시험 안내 (2026-11-08)

독자: VPyLab을 처음 사용하는 교사(다른 학교 정보 교사 포함), 학생
문체: 합쇼체(~합니다), 평서형. 청유("~해 보세요")·구어체 금지. 은유·의인화·과장 금지. 대시(—)로 문장 잇기 금지
형식: 블록 하나의 출력은 문단 하나. 빈 줄 금지. 목록 기호 금지. "쓰다"(사용 의미) 대신 "사용하다", "단추" 대신 "버튼", "뜨다" 대신 "표시되다". KEEP 조각은 굵게 표시·백틱까지 그대로
공통 사실: 2026년 11월 8일 VPyLab의 구글 OAuth 동의 화면을 "테스트 중"에서 "프로덕션"으로 게시했다. 요청하는 권한(openid, email, profile, drive.file)은 모두 구글이 민감하지 않은 범위로 분류해 구글 인증 심사 대상이 아니다

[블록 1] 위치: README.ko 드라이브 저장 실험 절, "통과 항목" 문단 다음 / 역할: 지금의 제한 사항
- 사실: 2026년 11월 8일 구글 OAuth 앱을 프로덕션으로 게시해 구글 계정이 있으면 누구나 승인할 수 있음. 테스트 사용자로 등록할 필요가 없음
- 사실: 학교 구글 워크스페이스 계정은 관리자가 외부 앱을 제한하면 승인이 막힐 수 있음
- 사실: 액세스 토큰은 약 1시간 지속되며 갱신 토큰은 없음. 만료되면 코드를 초안으로 남기고 다시 승인을 요청함
- 분량: 4문장

[블록 2] 위치: GUIDE 5장(학교 구글 계정), 관리 콘솔 표 아래 / 역할: 앱의 게시 상태

- 사실: 요청하는 권한이 모두 민감하지 않은 범위여서 구글 인증 심사 대상이 아님
- 사실: 학교 계정이 막히면 원인은 대부분 위 표의 관리자 설정임

- 사실: 앱은 프로덕션 상태라 계정 등록 문제로 막히지 않음
- 사실: 학교 계정이면 학교 관리자가 외부 앱을 제한했을 가능성이 높음. 정보 담당 교사에게 5장의 관리 콘솔 설정을 요청함
- 사실: 18세 미만으로 지정된 학생 계정은 관리자가 앱을 설정하기 전에는 사용할 수 없음
- 사실: 브라우저에 다른 구글 계정으로 로그인한 상태인지도 확인함
