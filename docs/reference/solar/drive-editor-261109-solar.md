### 블록 D
편집기의 저장 버튼과 Ctrl/Cmd+S는 코드를 학생 본인 구글 드라이브의 VPyLab 폴더에 저장합니다. 처음 저장할 때는 저장을 누르면 창이 열리고 구글 계정으로 로그인한 뒤 구글 승인 창에서 계정을 고르고 Google Drive 파일 체크 상자를 직접 체크한 다음 계속합니다. 이후 파일 이름을 적고 드라이브에 저장을 누르면 저장이 완료되며, 그다음부터는 저장을 누르면 같은 파일에 바로 저장되고 버튼에 저장됨이 잠시 표시됩니다. 도구 줄의 내 드라이브 버튼을 누르면 VPyLab 폴더의 파일 목록이 나오며 파일을 골라 열거나 새 코드로 시작하거나 로그아웃하거나 권한을 철회할 수 있습니다. 같은 파일을 다른 탭이나 기기에서 먼저 저장했으면 내 코드를 사본으로 저장, 드라이브 내용 불러오기(내 변경은 버림), 내 코드로 덮어쓰기 중에서 선택합니다. 구글 권한은 약 1시간 유지되며 만료되면 다시 승인을 누르면 같은 계정으로 이어서 저장합니다. 페이지를 새로 고치면 다시 로그인해야 합니다. 저장하지 못한 변경은 계정별로 이 브라우저에 초안으로 남고 그 파일을 다시 열 때 불러올지 묻습니다. 초안은 14일이 지나면 그 컴퓨터에서 저장 창을 다시 열 때 지워집니다. 이전 내용은 구글 드라이브에서 그 파일의 버전 기록으로 확인합니다.

1. 만들기 화면에서 저장을 누르면 저장 창이 열립니다.
2. 구글 계정으로 로그인 버튼을 눌러 구글 승인 창을 엽니다.
3. 승인 창에서 계정을 고르고 Google Drive 파일 체크 상자를 직접 체크한 뒤 계속합니다.
4. 파일 이름을 적고 드라이브에 저장 버튼을 누릅니다.
5. 저장됨 표시가 나타나면 처음 저장이 완료됩니다.

### 블록 E

### 블록 F
만들기 화면의 저장은 학생 본인 구글 드라이브의 VPyLab 폴더에 저장합니다. 구글 승인 화면의 Google Drive 파일 체크 상자는 처음에 비어 있어 직접 체크해야 합니다. 승인 창은 팝업이므로 막히면 주소창에서 허용합니다. 교사 계정과 학생 계정 두 가지로 시험합니다.

- [ ] 만들기 화면에서 저장을 누르고 구글 계정으로 로그인한 뒤 Google Drive 파일을 체크하고 계속합니다.
- [ ] 파일 이름을 적고 드라이브에 저장한 뒤 코드를 바꾸고 다시 저장을 눌러 저장됨을 확인합니다.
- [ ] 페이지를 새로 고친 뒤 내 드라이브에서 다시 로그인하고 그 파일을 열어 바꾼 내용이 그대로인지 확인합니다.
- [ ] 구글 드라이브의 VPyLab 폴더에 그 파일이 있는지 확인합니다.
- [ ] 학생 계정으로 반복하고 막히면 화면 문구를 그대로 기록합니다.

### 블록 G
만들기 화면의 저장과 실험 페이지인 vpylab.pages.dev/drive-lab은 구글 로그인으로 openid, email, profile, drive.file 권한을 요청합니다. drive.file 권한으로는 이 앱이 만든 파일만 볼 수 있고 드라이브의 다른 파일은 볼 수 없습니다. 파일은 사용자 본인의 구글 드라이브 VPyLab 폴더에 저장되며 VPyLab 관리자는 볼 수 없습니다. 구글 로그인 스크립트는 저장 창이나 내 드라이브 창을 열 때만 불러옵니다. 구글 접근 토큰은 페이지 메모리에만 있고 새로 고침하면 사라집니다. 저장하지 못한 초안은 계정별로 이 브라우저에 남고 14일이 지나면 그 컴퓨터에서 저장 창을 다시 열 때 지워집니다. 권한은 창의 권한 철회 버튼이나 myaccount.google.com/connections에서 거둘 수 있습니다.
