# GitHub 연동 갤러리 안내 문구: 솔라 집필 기록 (2026-11-12)

- 사용한 곳
  - 화면 문구(블록 1~13): `client/src/gallery/gallery-text.js`. 갤러리 화면 `client/src/components/gallery/GitHubGalleryView.jsx`, 팀 프로젝트 창 `client/src/components/github/GitHubProjectDialog.jsx`
  - 공개판 개인정보 처리방침의 "갤러리 (선택 기능)" 구역(블록 14): `client/src/pages/Privacy.jsx`
  - 교사용 문서(블록 15~20): `docs/GALLERY_GITHUB.md`
  - 승인 대기 목록 파일의 설명(블록 21): `scripts/gallery/gallery-index.mjs`의 `PENDING_TEXT.intro`
  - 승인 파일 양식의 머리말(블록 22): `scripts/gallery/approvals.template.txt`
- 역할 분담: 클로드가 사실·구성·분량을 설계서로 정하고, 솔라 프로4(`solar-pro4`, temperature 0.4)가 문장을 썼습니다. 클로드는 사실과 버튼 이름만 대조했고 문체는 고치지 않았습니다.
- 사실의 근거: 버튼 이름과 동작은 `GitHubProjectDialog.jsx`, `githubSession.js`, `github-api.js`, `GitHubGalleryView.jsx`에서, 목록과 승인 규칙은 `scripts/gallery/gallery-index.mjs`와 `.github/workflows/gallery-index.yml`에서 읽었습니다. GitHub 계정의 나이 기준(13세)은 기존 팀 프로젝트 안내와 같습니다.
- 기계 검증: `verify_blocks.py` 1차에서 "검증 통과: 수치·KEEP·분량·금지어 모두 이상 없음".
- 솔라의 문장에서 바꾼 곳(사실 때문에 한 곳): 블록 20의 "문제가 생긴 작품은 차단 줄로 바로 내릴 수 있습니다."에서 "바로"를 뺐습니다. 차단은 다음 목록 갱신 때 반영되므로 "바로"는 사실과 다릅니다. 설계서의 사실 줄에 "바로"가 있었던 것이 원인입니다.
- 클로드가 직접 쓴 것: 버튼과 제목 같은 짧은 문구(갤러리에 올리기, 갤러리에서 내리기, 미리보기 그림 새로 올리기, 실행 화면 열기, 코드 보기 등), 승인 줄의 형식 설명(코드 블록과 양식의 형식 줄), 목록 브랜치의 README 표, 영어 번역(`client/src/i18n/catalogs/en-ui-text.json`).
