# 브리프 — 짧은 공유 주소(/s/이름) 도입에 따른 문구 (2026-11-09)

독자: VPyLab 공개판(vpylab.pages.dev)을 사용하는 중·고등학생, 교사, 학부모. 블록 13~14는 저장소를 관리하는 교사·개발자
문체: 합쇼체(~합니다), 평서형. 청유("~해 보세요") 남용·구어체 금지. 은유·의인화·과장 금지. 대시(—)로 문장 잇기 금지
형식: 블록 하나의 출력은 문단 하나(블록 2~12의 화면 문구는 한 줄). 빈 줄로 나누지 말 것. 목록 기호 금지. 굵게 표시 금지. "쓰다"(사용 의미) 대신 "사용하다", "단추" 대신 "버튼". KEEP 조각은 철자 그대로
공통 사실
- 공개판에서 도구 → 공유를 누르면 코드와 제목이 Cloudflare D1 저장소에 저장되고 짧은 주소가 만들어진다
- 이름을 정하지 않으면 주소 끝에 무작위 6자가 붙는다(예: vpylab.pages.dev/s/k7x2p9)
- 공유 창 아래 칸에서 이름을 정하면 vpylab.pages.dev/s/정한이름 주소가 된다. 이름은 영어 소문자, 숫자, 하이픈(-)으로 3~30자이고, 먼저 정한 사람이 사용한다
- 같은 브라우저에서 같은 이름을 다시 정하면 그 주소의 코드가 지금 코드로 바뀐다. 다른 브라우저나 기기에서는 바꿀 수 없다
- 로그인과 회원 가입은 여전히 없다

[블록 1] 처리방침 소제목 "3. 공유 링크" 아래 본문 / 역할: 공유할 때 무엇이 어디에 얼마나 저장되는지
- 사실: 도구 → 공유를 누르면 코드와 제목이 Cloudflare D1 저장소에 저장되고 짧은 주소가 만들어짐
- 사실: 주소를 아는 사람은 누구나 그 코드를 볼 수 있으므로 코드와 제목에 이름, 연락처 같은 개인정보를 넣지 않아야 함
- 사실: 같은 브라우저에서만 고칠 수 있도록 수정 열쇠가 이 브라우저의 저장 공간(localStorage)에 남고, 저장소에는 열쇠를 변환한 값만 저장됨
- 사실: 짧은 시간에 너무 많이 만드는 것을 막으려고 IP 주소를 변환한 값을 사용함. IP 주소 자체는 저장하지 않고, 변환한 값도 2분 안에 지움
- 사실: 공유한 코드는 삭제 요청이 있을 때까지 보관함. 지우려면 GitHub 이슈에 지울 주소만 적으면 됨
- 사실: 저장소가 응답하지 않을 때는 코드를 압축해 링크 주소 안에 담은 긴 링크를 대신 만들며, 이때는 저장소에 저장하지 않음
- KEEP: Cloudflare D1, localStorage, GitHub
- 분량: 6문장

[블록 13] 사용 안내서(GUIDE) "공유" 문단 / 역할: 공유 방법 전체
- 사실: 도구 → 공유를 누르면 짧은 주소(예: vpylab.pages.dev/s/k7x2p9)가 만들어지고 클립보드에 복사됨
- 사실: 같은 창 아래 "짧은 이름 정하기" 칸에 이름을 넣고 "이 이름으로 만들기"를 누르면 vpylab.pages.dev/s/정한이름 주소가 됨. 규칙은 영어 소문자, 숫자, 하이픈(-) 3~30자이고 먼저 정한 사람이 사용함
- 사실: 같은 브라우저에서 같은 이름을 다시 정하면 그 주소의 코드가 지금 코드로 바뀜. 다른 브라우저나 기기에서는 바꿀 수 없음
- 사실: 같은 창에서 QR 보기를 누르면 그 주소의 QR 코드가 나오고, 임베드 코드 복사로 다른 웹페이지에 작품을 넣을 수 있음
- 사실: 주소나 QR 코드로 열면 편집기가 아니라 실행 화면이 먼저 나오고, 클릭하여 시작을 누르면 작품이 실행됨. 왼쪽 위 코드 보기를 누르면 만들기 화면에서 같은 코드를 볼 수 있음
- 사실: 주소를 아는 사람은 누구나 코드를 볼 수 있으므로 개인정보를 넣지 않아야 함. 공개판에는 갤러리가 없음
- KEEP: 도구 → 공유, 짧은 이름 정하기, 이 이름으로 만들기, QR 보기, 임베드 코드 복사, 클릭하여 시작, 코드 보기, vpylab.pages.dev/s/k7x2p9
- 분량: 7~8문장

[블록 14] README(한국어) 기능 목록의 공유 항목 / 역할: 한 문단 소개
- 사실: 공개판에서도 도구 → 공유로 짧은 주소를 만들 수 있음. 이름을 정하면 vpylab.pages.dev/s/정한이름, 정하지 않으면 무작위 6자
- 사실: 주소나 QR 코드로 열면 실행 화면이 먼저 나옴. 임베드 코드도 제공함
- 사실: 코드와 제목만 Cloudflare D1에 저장하며 로그인은 필요 없음
- KEEP: 도구 → 공유, Cloudflare D1
- 분량: 3~4문장

[블록 15] README(한국어) "개인정보와 데이터" 문단 / 역할: 공개판이 무엇을 어디에 두는지
- 사실: 공개판에는 계정이나 로그인이 없고, VPyLab이 개인정보를 저장하는 서버나 데이터베이스도 없음
- 사실: 저장소는 공유 주소용 Cloudflare D1 하나뿐이며, 공유를 누를 때 코드와 제목만 저장됨
- 사실: 코드는 학생 브라우저 안에서 실행됨. 진행 기록, 테마, 언어, 메인 화면 설정은 이 브라우저(localStorage)에, 연습 초안은 브라우저 탭(sessionStorage)에 보관됨. 브라우저 데이터를 지우면 사라지며 다른 기기로 옮겨지지 않음
- 사실: 외부 요청은 웹 글꼴(Google Fonts, Fontshare)을 받을 때 이루어짐. 파이썬 엔진은 vpylab.pages.dev에서 받으며, 실패할 때만 jsDelivr나 unpkg를 사용함
- KEEP: Cloudflare D1, localStorage, sessionStorage, Google Fonts, Fontshare, vpylab.pages.dev, jsDelivr, unpkg
- 분량: 6~7문장

[블록 16] 배포 문서(DEPLOY_TWO_EDITIONS) "짧은 공유 주소" 절 첫 문단 / 독자: 관리자 / 역할: 구조 설명
- 사실: 오픈소스 판의 공유 주소는 Cloudflare Pages 함수(functions/api/share/)가 만들고 읽으며, 규칙은 cloudflare/share-core.js 한 곳에 있음
- 사실: 저장소는 D1 데이터베이스 vpylab-shares(아시아·태평양 지역)이고, wrangler.toml에서 DB라는 이름으로 연결함. 따로 운영하는 서버는 없고, 정적 파일과 함께 배포됨
- 사실: IP 주소를 변환할 때 섞는 비밀값 SHARE_SALT는 Pages 비밀값으로 넣어 둠
- 사실: 저장소가 응답하지 않으면 앱은 코드를 주소에 담은 링크(#code=)로 대신하므로 공유가 막히지 않음
- 사실: 수업용 판은 지금처럼 Railway 서버가 Supabase에 무작위 8자 주소로 저장하며, 이름 정하기는 아직 지원하지 않음
- KEEP: functions/api/share/, cloudflare/share-core.js, vpylab-shares, wrangler.toml, DB, SHARE_SALT, #code=, Railway, Supabase
- 분량: 5~6문장

[블록 17] 배포 문서 같은 절 둘째 문단 / 역할: 표를 바꾸거나 주소를 지우는 방법 안내(명령어는 따로 코드 블록으로 붙이므로 문장에는 넣지 않음)
- 사실: 표 구조는 cloudflare/migrations/ 폴더에 있고, 바꾼 뒤에는 아래 첫 번째 명령으로 원격 데이터베이스에 반영함
- 사실: 부적절한 공유 주소나 삭제 요청이 들어온 주소는 아래 두 번째 명령으로 지움. 명령은 Cloudflare 계정에 로그인한 컴퓨터에서 실행함
- 사실: 무료 사용량은 하루에 쓰기 10만 건, 읽기 500만 건이며 학교 수업 규모로는 비용이 들지 않음
- KEEP: cloudflare/migrations/
- 분량: 3문장
