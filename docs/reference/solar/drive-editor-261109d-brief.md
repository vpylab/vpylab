# 브리프 — 사용 안내서 자주 묻는 질문 두 개 (2026-11-09)

독자: VPyLab 공개판을 사용하는 교사와 학생
문체: 합쇼체(~합니다), 평서형. 구어체·은유·과장 금지. 대시(—)로 문장 잇기 금지
형식: 블록 하나의 출력은 문단 하나. 목록 기호·굵게 표시 금지. 버튼 이름은 KEEP 철자 그대로

[블록 1] 질문 "학생 코드가 서버로 전송되나요?"의 답 / 역할: 코드가 어디로 가는지 정확히
- 사실: 코드는 학생 브라우저 안에서 실행되며, 실행을 위해 VPyLab 서버로 코드를 보내지 않음
- 사실: 저장을 누르면 코드는 학생 본인 구글 드라이브의 VPyLab 폴더로만 전송됨
- 사실: 도구 → 공유를 누를 때만 코드와 제목이 공유 주소용 저장소(Cloudflare D1)에 저장됨
- KEEP: 도구 → 공유, Cloudflare D1, VPyLab
- 분량: 3문장

[블록 2] 질문 "공용 컴퓨터에서 주의할 점은 무엇인가요?"의 답 / 역할: 공용 컴퓨터에서 다음 사람에게 계정이나 초안이 남지 않게
- 사실: 내 드라이브 창의 로그아웃을 누르면 이 브라우저에 남은 그 계정의 초안을 지울지 묻고, 공용 컴퓨터에서는 지우는 것이 안전함
- 사실: VPyLab에서 로그아웃해도 브라우저의 구글 로그인 상태는 바뀌지 않음. 로그아웃 뒤 나오는 링크로 구글 계정에서도 로그아웃함. 그러지 않으면 다음 사람이 계정 선택 창에서 앞 사람 계정을 고를 수 있음
- 사실: 드라이브 실험 페이지의 로그아웃도 같은 방식으로 동작함
- KEEP: 내 드라이브, 로그아웃
- 분량: 4~5문장
