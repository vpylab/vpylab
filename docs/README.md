# Documentation index

English · most documents below are in Korean unless marked (EN).

This folder holds two kinds of files. **Living documents** describe how VPyLab works now and are kept up to date. **Dated reports** record a review, test or release on a given day and are not updated afterwards. If a dated report disagrees with a living document or with the code, the code is right.

## Dated reports

Files whose names end in a date (`…_2026-11-07.md`) and the folders `content-review/`, `github-flow-review/`, `github-two-account-test/`, `month-projects/`, `project-path-review/`, `reports/`, `three-way-review/`, `review-figures/`, `guide-captures/` are records. They explain why something was built the way it was. They are not instructions.

`reference/` holds writing briefs and drafts used to produce interface text.

## Adding a document

- Put a living document here and add it to the table above.
- Name a report with its date and do not edit it later; write a new one instead.
- New living documents for contributors should be in English, or English first with a Korean section.
