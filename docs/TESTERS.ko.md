# 다른 학교 선생님을 위한 시험 안내

이 문서는 VPyLab 공개판(vpylab.pages.dev)을 다른 학교의 기기와 구글 계정에서 시험하기 위한 안내입니다. 당곡고에서는 교사 계정과 개인 gmail 계정으로 시험을 마쳤고, 학생 계정과 다른 학교의 관리자 정책은 아직 확인하지 못했습니다. 시험에는 30분 정도 걸립니다. 결과를 받아 학교마다 필요한 설정을 안내문에 반영합니다.

## 준비물

| 준비물 | 용도 |
|---|---|
| 수업에서 사용하는 기기(학교 컴퓨터, 크롬북, 태블릿) | 1장과 2장 |
| 휴대폰 | 1장의 QR 코드 시험 |
| 교사 구글 계정 | 2장 |
| 학생 구글 계정(학생 시험용 계정이 있으면 그 계정) | 2장 |

## 1. 기본 기능 (계정 없이)

- [ ] https://vpylab.pages.dev 에서 상단 **트레이닝** → **기초 코스 시작하기**를 누르고 첫 차시 코드를 실행합니다. 3D 화면이 표시되고 소리가 들리는지 확인합니다.
- [ ] **만들기**에서 코드를 실행한 뒤 **정지**를 누릅니다. 움직임과 소리가 멈추는지 확인합니다.
- [ ] **도구 → 공유**를 누르고 **QR 보기**의 QR 코드를 휴대폰으로 찍습니다. 휴대폰에 실행 화면이 먼저 표시되고, **클릭하여 시작**을 누르면 작품이 실행되는지 확인합니다.
- [ ] **도구 → HTML 내려받기**로 받은 파일을 브라우저로 열어 작품이 실행되는지 확인합니다.

## 2. 구글 드라이브 저장 (구글 계정)

만들기 화면의 저장은 학생 본인 구글 드라이브의 VPyLab 폴더에 저장합니다. 구글 승인 화면의 Google Drive 파일 체크 상자는 처음에 비어 있어 직접 체크해야 합니다. 승인 창은 팝업이므로 막히면 주소창에서 허용합니다. 교사 계정과 학생 계정 두 가지로 시험합니다.

- [ ] 만들기 화면에서 저장을 누르고 구글 계정으로 로그인한 뒤 Google Drive 파일을 체크하고 계속합니다.
- [ ] 파일 이름을 적고 드라이브에 저장한 뒤 코드를 바꾸고 다시 저장을 눌러 저장됨을 확인합니다.
- [ ] 페이지를 새로 고친 뒤 내 드라이브에서 다시 로그인하고 그 파일을 열어 바꾼 내용이 그대로인지 확인합니다.
- [ ] 구글 드라이브의 VPyLab 폴더에 그 파일이 있는지 확인합니다.
- [ ] 학생 계정으로 반복하고 막히면 화면 문구를 그대로 기록합니다.

## 3. 결과 보내기

결과는 GitHub 이슈(github.com/vpylab/vpylab/issues)로 보내거나 안내해 준 운영자에게 직접 보냅니다. 이슈는 누구나 볼 수 있으므로 학생 이름, 학생 이메일 주소 같은 개인정보는 적지 않습니다. 화면 캡처에서도 가립니다. 오류가 나면 화면에 나온 문구를 그대로 적어 주면 원인을 찾기 쉽습니다.

| 적을 것 | 예 |
|---|---|
| 학교 구글 워크스페이스 | 사용 여부, 교육용 여부(도메인 주소는 적지 않아도 됩니다) |
| 기기와 브라우저 | 크롬북 / 크롬 |
| 계정 종류 | 교사, 학생(18세 미만 지정 여부를 알면 함께) |
| 1장 결과 | 항목마다 통과 또는 실패 |
| 2장 결과 | 승인, 저장, 다시 열기의 결과와 오류 문구 |

## 4. 시험 뒤 정리

실험 페이지의 **권한 철회** 버튼을 누르면 VPyLab에 준 구글 권한이 거두어집니다. 구글 드라이브의 VPyLab 폴더는 지워도 됩니다. 공용 컴퓨터라면 시험 뒤 로그아웃합니다.
